# Token Station Logo Exploration — Research Notes

## Brief

Token Station is a local-first desktop AI request router. It decouples AI agents such as Claude Code, Codex, Gemini CLI, Cursor, and OpenCode from model providers, then applies direct, tiered, or quota-first routing. The mother brand therefore needs to communicate controlled routing, local ownership, and dependable developer infrastructure—not cryptocurrency, chat, or a generic “AI” sparkle.

Primary in-product constraints:

- wordless 1:1 mark;
- recognisable at 16–32 px;
- convertible to a one-colour tray icon;
- usable on both `#F4F6FA` and `#111620` UI canvases;
- no dependence on gradients, glow, glass, tiny nodes, or fine crossings.

Local evidence:

- `README.zh-CN.md` documents the local gateway and routing modes.
- `apps/desktop/src/App.css` defines the final cool grey / indigo UI palette.

## What the earlier 25 concepts got wrong

The earlier set is operationally complete but visually too homogeneous: rounded app-icon tiles, blue-purple gradients, centre dots, radiating paths, and multi-line network diagrams repeat across most concepts. Several marks collapse at favicon size or read as USB, sync, VPN, smart-home, battery, chart, Web3, or railway utilities. Its numeric scores are designer self-ratings, not user tests, trademark review, or competitor-distance evidence.

The useful inheritance is semantic rather than graphical: one controlled gateway, local containment, deterministic route choice, and a neutral station between agents and providers.

## Current competitor space (verified 2026-08-29)

- [OpenRouter brand refresh](https://openrouter.ai/blog/announcements/brand-refresh/): the July 2026 identity uses a geometric OR ligature built on a mathematical/Bauhaus framework and a bright purple-led colour system. The older opposing-arrow mark is no longer the current reference.
- [OpenRouter product](https://openrouter.ai/): positions itself as a unified interface for models and providers.
- [CC Switch canonical repository](https://github.com/farion1231/cc-switch): its current app icon uses multiple rounded coloured bars radiating from a centre, occupying the “multi-model burst” territory.
- [LiteLLM](https://www.litellm.ai/): prominently uses a fast-train motif, so a literal locomotive or speed-line identity would be too close and too literal.
- [Portkey AI Gateway](https://portkey.ai/features/ai-gateway): uses a rounded portal/chevron vocabulary, while the company is transitioning the product toward PRISMA AIRS.
- [Helicone Gateway](https://docs.helicone.ai/gateway/overview): uses the familiar isometric cube/hex infrastructure language.
- [Vercel AI Gateway](https://vercel.com/ai-gateway): inherits Vercel's black/white triangle and grid-led developer-system aesthetic rather than a strong independent gateway mark.

Crowded motifs to avoid: centre bursts, purple circular letter ligatures, arrows and chevrons, node networks, infinity loops, hexagons/cubes, train heads, lightning bolts, keys/plugs, generic shields, and obvious TS monograms.

## Five new visual languages

1. **Switch Cut / 切轨印记** — a disciplined evolution of the current ink/vermilion switch DNA, using a decisive cut rather than a routing diagram.
2. **Local Aperture / 本地孔径** — a heavy boundary with one controlled ingress and no security-software clichés.
3. **Dual-track Exchange / 双轨换线** — two constant-width bands exchange position around a square negative-space core; no arrows, nodes, or loop.
4. **Token Rack / 令牌机架** — large, machine-readable slots and packets; token as a data unit rather than coin or quota chart.
5. **Signal Control / 精密信号** — reductive Swiss/industrial control marks built from a baseline, interruption, latch, or detent.

## Production method

Each concept starts with an independent built-in image-generation pass for broader silhouette exploration. Because bitmap generation can introduce unrequested gradients, pseudo-transparency, or dirty edges, the production deliverable is then redrawn as a self-contained flat SVG and rendered to PNG. This hybrid method keeps the creative range of image generation while preserving the small-size and colour-control requirements of a real application logo.
