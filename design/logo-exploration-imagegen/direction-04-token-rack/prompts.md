# Direction 04 — Token Rack

This direction treats a token as a machine-readable data unit, registered slot, or cartridge. It explicitly avoids crypto coins, tickets, batteries, dashboards, database stacks, literal server racks, and node diagrams.

## Production method

- Ideation: OpenAI built-in `image_gen`, one independent call for each concept. The generated raster was used only as a structural sketch.
- Production: each selected idea was redrawn as a self-contained SVG with uniform solid fills.
- Export: matching 1024×1024 PNG files were produced using `rsvg-convert -w 1024 -h 1024`.
- Final contract: `viewBox="0 0 512 512"`; transparent canvas; `<g id="mark">`; no text, images, references, gradients, filters, masks, or shadows; only graphite `#182133` and vermilion `#F04B2F`.

## 01 Perforated Unit

```text
Use case: logo-brand
Asset type: Token Station app logo concept — Perforated Unit, one isolated mark only
Primary request: Explore an original “Perforated Unit” symbol for Token Station, a local-first desktop AI request router. Treat a token as one machine-readable data unit: a single massive horizontal rectangular graphite block whose top and bottom edges each contain one opposing square cut. The two square cuts are staggered and face each other to create a controlled internal passage without making a literal hole, ticket, connector, or device. Add one restrained vermilion selection insert at the passage.
Style/medium: severe flat vector geometry; hard industrial editorial mark; compact, registration-minded, no decorative detail
Composition/framing: exactly one centered symbol on a genuinely transparent square canvas; 15% safety margin; near-square footprint; strong silhouette with only two large edge cuts; clear at 32 px
Color palette: perfectly uniform graphite #182133 and vermilion #F04B2F only
Constraints: one primary heavy block; two opposing square notches; one small red insert; solid hard-edged fills only; no text, letters, background, border, app tile, mockup, gradient, lighting, texture, shadow, glow, bevel, depth or 3D
Avoid: ticket or coupon silhouette, USB connector, SIM card, plug, battery, coin, crypto token, chart, gauge, database stack, server rack drawing, barcode, nodes, dots, network graph, arrows, blue/purple, OpenRouter/CC Switch/OpenAI/Anthropic similarity, watermark
```

Production cleanup: the two side-by-side raw blocks were rejected. The final is one sheared graphite data slice with unequal slots on opposite sides and at different heights; one short vermilion insert occupies only the deeper slot.

Acceptance: single dominant asymmetric silhouette, two offset cuts of different depth, transparent background, no H symmetry, coupon perimeter, contacts, or device details.
