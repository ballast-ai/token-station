# 产品功能总览

token-station 是一个**本地回环的 LLM 代理**：IDE、Agent 或任何 OpenAI 兼容
客户端把请求发到本机 `127.0.0.1:8787`，token-station 按你写的规则把每个请求
路由到合适的上游（你自己的 API key、你本机的模型），路由决策全部发生在你的
机器上，prompt 的任何内容都不会离开它。

```
IDE / Agent ──▶ 127.0.0.1:8787 ──▶ 规则 → hint → 启发式 → 默认池
                                        │
                     ┌──────────────────┼──────────────────┐
                     ▼                  ▼                  ▼
               api.openai.com     api.groq.com      localhost:11434
               （你的 key）        （你的 key）       （你的 Ollama）
```

## 核心功能

| 功能 | 说明 | 详见 |
|---|---|---|
| **OpenAI 兼容代理** | 暴露 `/v1/chat/completions`、`/v1/models`，支持流式（SSE）。现有 IDE / Agent 无需改代码，改 Base URL 即可接入。 | [CLI 命令参考](CLI-命令参考.md) |
| **四层本地路由** | rules → hints → heuristic → default，第一个给出答案的层胜出。请求 `auto` 时由路由器决策；请求具体模型就给你那个模型。 | [路由机制.md](路由机制.md) |
| **BYOK 多上游** | 同时接多个上游（云端 BYOK / 本地 Ollama、vLLM 等），按池（pool）组织，规则把请求分配到池。 | [配置详解.md](配置详解.md) |
| **上游健康摘除** | 连续失败达到阈值的上游被临时摘除，冷却期后自动恢复，路由自动绕开。 | [路由机制.md](路由机制.md#上游健康与摘除) |
| **密钥托管** | key 存 OS 钥匙串，按请求解析、注入单个 header、永不进日志。也支持环境变量 / 文件降级路径。 | [配置详解.md](配置详解.md#凭证与-auth) |
| **本地指标** | 用量、错误、延迟、token 记录在本机 SQLite；`stats` 命令按时间窗 / 维度聚合。**不记录 prompt/response 内容**。 | [CLI 命令参考](CLI-命令参考.md#stats) |
| **沙箱 WASM 插件** | provider / agent adapter 是沙箱 WASM，只做协议翻译，没有网络、拿不到明文密钥。三层分发（内置 / 官方 / 第三方）。 | [插件体系.md](插件体系.md) |
| **可复现构建 + 签名发布** | 官方二进制可复现、Ed25519 签名；`upgrade` 匿名检查新版，仅在签名 manifest 验证通过后才保留。 | [../release/可复现构建与发布验证.md](../release/可复现构建与发布验证.md) |

## 隐私与安全边界（设计承诺）

token-station 押注的方向与常见云端网关相反：**路由是本地决策**。路由器、
规则、指标、密钥全部在本机。代理的外联目的地就是你配置的上游——外加一个
匿名版本检查，且只在你运行 `upgrade` 时发生，永不后台。

- **内容到不了磁盘。** 请求日志和指标库构建自一个字段全是数字、闭集枚举或
  你配置里名字的记录类型——没有一个列能装下 prompt。测试用金丝雀直接 grep
  数据库原始字节来证明这一点。
- **key 在 OS 钥匙串里**，按请求解析、注入一个 header、永不进日志。粘进
  URL 的 key 在配置加载时就被拒绝。
- **插件是沙箱 WASM。** provider adapter 只做协议翻译，没有网络、拿不到
  明文密钥；外泄闸门在凭据解析前核对每个出站请求是否指向你配置的端点。
- **默认开鉴权。** 本地虚拟 key 先于端口存在；回环是对网络的边界，不是对
  本机其他进程的。

## 当前状态

C1（最小可用客户端）已完成：流式代理、四层路由、上游健康摘除、OS 钥匙串
保管、指标库、CLI 管理面与发布工程。

- **今天即可用**：OpenAI 兼容上游，含 Ollama、vLLM 及多数 BYOK 供应商。
- **排期中**：Anthropic / Gemini 原生 adapter，按社区反馈推进。
