# Agents 紧凑列表界面修正规格

日期：2026-07-20
状态：用户已确认高保真演示，等待书面规格复核

## 1. 问题与根因

当前 Agents 页面在系统启用深色外观时，通过局部
`@media (prefers-color-scheme: dark)` 单独切换为深色控制台样式；应用外壳和其他页面仍固定为浅色，因此同一窗口出现两套互不一致的主题。

此外，当前页面使用大标题、独立网格背景、双列大卡片和装饰轨道，信息密度与现有 Token Station 的面板、供应商列表和桌面窗口尺寸不一致。Agent 数量继续增加后，页面会快速变长，实例选择、版本状态和接入操作也不易扫描。

## 2. 目标

- Agents 页面始终与现有 Token Station 浅色视觉体系一致。
- 在默认桌面窗口内快速扫描 Agent、版本、来源和状态。
- 支持未来继续增加 Agent，而不依赖越来越长的大卡片网格。
- 复用现有扫描、版本准入、接入预览、确认、快照与恢复能力。
- 保持现有安全边界，不修改 `crates/router-core/**`。

## 3. 非目标

- 不新增或修改 Agent 发现、兼容判断、Connector、事务或快照协议。
- 不自动安装、升级、启动或修复第三方 Agent。
- 不在本次修正中建设全局深色主题。
- 不修改路由算法、规则匹配、评分、选池、排序、`RouterConfig` 或 `Decision`。

## 4. 已确认方案

采用“浅色紧凑列表 + 单行行内展开”。

### 4.1 页面结构

1. 保留现有 Token Station 顶栏和标签导航。
2. 使用一个标准浅色面板承载页面标题、说明和“重新扫描”按钮。
3. 面板底部展示“已发现、可接入、已接入”三个摘要指标，以及只读扫描状态。
4. 代理未启动等全局提示使用现有浅色通知条，不使用深色控制台横幅。
5. Agent 列表使用单列结构，列为：
   - 客户端；
   - 版本；
   - 安装来源；
   - 状态。
6. 每个 Agent 默认只占一行；点击后在该行下方展开详情。

### 4.2 行内展开

- 同一时间最多展开一个 Agent。
- 再次点击已展开行时收起。
- 展开区左侧显示安装实例和兼容说明。
- 展开区右侧显示配置格式、快照状态、连接状态和操作按钮。
- 多安装实例必须先选择规范化真实路径，之后才能判断是否允许生成接入计划。
- 代理未启动时，“预览接入”保持禁用；扫描和查看快照仍可用。
- 未安装 Agent 的展开区只说明扫描范围和重新扫描入口，不提供安装按钮。

### 4.3 状态表达

状态使用文字与轻量色标共同表达，不依赖颜色作为唯一信号：

| 状态 | 文案示例 | 视觉语义 |
|---|---|---|
| 已验证且可写 | 可接入 | 绿色 |
| 多实例待选择 | 需选择 | 琥珀色 |
| 未发现安装 | 未安装 | 中性灰 |
| 未知版本 | 版本待验证 | 琥珀色 |
| 阻断版本或配置损坏 | 已阻止 / 只读保护 | 红色 |
| 已连接 | 已接入 | 绿色并显示断开入口 |

### 4.4 视觉规范

- 页面背景、面板、边框、按钮和字体复用 `App.css` 现有浅色语言。
- 删除 Agents 页面局部深色媒体查询、网格背景、大型控制台标题和左侧装饰轨道。
- 标题字号、圆角、阴影和间距与现有 `.panel`、`.provider-card`、`.btn` 保持一致。
- 原生下拉框统一为项目输入控件样式，避免 macOS 原生渐变和尺寸突变。
- 默认桌面窗口保持四列摘要；窄屏下隐藏次要列并将展开区改为单列。
- 支持键盘焦点、`aria-expanded` 和 reduced-motion。

## 5. 组件调整

- `Agents.tsx`
  - 将控制台式 hero 与 safety strip 改为标准页面头和摘要。
  - 管理唯一展开的 Agent ID。
- `AgentCard.tsx`
  - 改为可展开的列表行组件；保留原有状态计算、实例选择和回调契约。
  - 组件名称可调整为 `AgentRow`，但不改变 API 数据结构。
- `AgentSnapshotList.tsx`
  - 保持现有功能，可继续在列表后方或对话框中展示。
- `AgentChangePreview.tsx`
  - 保持现有预览和确认流程，只统一浅色视觉。
- `App.css`
  - 删除 Agents 页面独立主题变量和局部深色覆盖。
  - 新增紧凑列表、展开区和响应式规则。

## 6. 数据与安全边界

本次仅改变展示和交互编排：

```text
scanAgents()
  → AgentView[]
  → 紧凑列表
  → 选择安装实例
  → planAgentConnection()/planAgentDisconnect()
  → 现有差异确认对话框
  → 现有 apply 流程
```

不改变后端命令参数、计划令牌、兼容目录、配置写入、快照或恢复语义。所有写入仍必须经过“预览 → 用户确认 → 加密快照 → revision 复核 → 原子写入 → 自检/恢复”。

## 7. 错误与空状态

- 初次扫描：显示标准浅色加载行。
- Registry 为空：说明没有可展示 Agent，并保留重新扫描入口。
- 扫描错误：使用现有错误横幅，保留已成功读取的行。
- 多实例：明确要求选择真实路径，不自动选择可能错误的实例。
- 未知或阻断版本：展示原因，禁用接入操作，扫描和快照不受影响。
- 代理未启动：页面顶部只显示一次全局说明，各行不重复大段警告。

## 8. 验收标准

1. 系统处于浅色或深色外观时，Agents 页面都与当前固定浅色应用外壳一致。
2. 五个 Agent 在默认桌面窗口内以紧凑单列表现，页面不再出现深浅主题割裂。
3. 点击行可展开；切换到另一行时，上一行自动收起。
4. 多实例选择、已验证、未知、阻断、未安装、已连接状态均有明确文案。
5. 代理停止时接入操作禁用，扫描和快照入口可用。
6. 现有预览、确认、断开和恢复功能契约不变。
7. Vitest 覆盖展开/收起、实例选择、按钮准入和窄屏语义。
8. 前端测试、生产构建和 router-core 红线检查全部通过。
