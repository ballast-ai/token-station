# Agent 接入区与安装选择器界面设计

- 日期：2026-07-21
- 范围：桌面端五个 Agent 详情页的接入区
- 前置设计：[2026-07-21-desktop-agent-navigation-ui-design.md](./2026-07-21-desktop-agent-navigation-ui-design.md)

## 1. 目标

统一 Claude Code、Codex、OpenCode、OpenClaw 和 Hermes 的接入区布局，避免长路径挤压导致“一键接入”换行，同时保留多安装实例的明确选择能力。

## 2. 确认的交互

### 2.1 路径隐藏

- Agent 标题下不再展示 `canonical_path`。
- 类似 `/Users/.../claude.exe` 或 `/Applications/.../codex` 的完整路径不出现在主界面、选择按钮或选择列表中。
- 完整路径仍作为内部安装实例 ID，不改变 plan/apply 命令参数。

### 2.2 单安装实例

- 不显示“选择安装”按钮。
- 接入区仅显示状态标签、简短说明和主操作按钮。

### 2.3 多安装实例

- 在主操作按钮前显示次级按钮“选择安装”。
- 点击后打开轻量弹出列表，不跳转新页面。
- 每项只显示可执行文件短名和已发现版本，例如 `claude.exe · v1.2.3`。
- 同名实例使用稳定序号区分，例如 `claude.exe · 1/2`；不回退到展示目录。
- 当前选中项显示勾选标记。选择后关闭列表，接入命令使用该实例的完整内部路径。

## 3. 布局与文案

接入区固定为一组水平操作：

```text
[可接入]  已发现兼容安装。  [选择安装]  [一键接入]
```

- “一键接入”禁止文字换行，保持一致最小宽度和高度。
- “选择安装”使用次级按钮样式，不与主操作争夺层级。
- “恢复 Agent 原始配置”同样禁止换行，但可以比“一键接入”更宽。
- 窄窗口允许整个操作组换到下一行，但单个按钮内部不换行。

## 4. 边界与安全

- 不改变 Agent 扫描、版本准入、多实例选择语义、计划令牌、快照、ownership、回滚或恢复流程。
- 不修改 CLI Host 路由、Canonical IR、WIT、插件 ABI 或 `crates/router-core/**`。
- 路径隐藏是展示层变更，不得使用短名代替内部唯一 ID。

## 5. 错误与边缘情况

- 没有发现安装时，显示“未发现”和现有引导文案，不显示选择按钮。
- 版本缺失时，选项仅显示短名，不显示虚构版本。
- 多个安装实例拥有同一短名和版本时，使用序号区分。
- 已选实例在重新扫描后消失时，回退到扫描结果中的第一项，延续现有行为。

## 6. 验收

1. 五个 Agent 的未接入主按钮均为单行“一键接入”，尺寸一致。
2. Agent 页面不展示任何完整可执行路径。
3. 单安装时没有“选择安装”按钮。
4. 多安装时可打开选择列表、识别当前项并切换实例。
5. 选择后 plan/apply 仍收到该实例的完整 `canonical_path`。
6. 浅色、深色和窄窗口下不出现按钮内换行或操作重叠。
7. 前端测试、生产构建和 `router-core` 红线检查通过。
