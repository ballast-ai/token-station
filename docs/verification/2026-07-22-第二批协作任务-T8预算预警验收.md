## 1. 验收结论

任务 #8 已形成闭环：用户可为支持的 Agent 设置预算上限、阈值、可选周期和到期预警；用量页展示健康、接近、超额、未知价格和期限状态，并可按 Agent 聚合。预算只读取 Receipt 已落库成本，不回算历史。

`BudgetStatus` 固定返回 `enforcement=observe_only`、`routing_affected=false`。真实代理集成测试在预算上限和阈值均设为极低值时仍得到 200，并验证请求确实命中上游，因此预算没有进入准入、路由、重试或 Provider 选择路径。

## 5. 安全与语义边界

- 预算只读取本地请求元数据，不读取 prompt/response。
- 未定价请求不会作为零成本静默通过，而是显示预算用量不完整。
- 成本直接使用 Receipt 当时固化的 `cost_micros`；预算查询没有更新旧行或价格版本的能力。
- 周期结束采用不包含终点的半开区间，新周期请求不会进入旧周期。
- 第一版不提供阻断开关、自动续期或订阅平台 API；这些均不属于本任务。
