# Agent 页面瞬态状态隔离验收

日期：2026-07-24
对应设计：`docs/design/2026-07-24-Agent页面瞬态状态隔离设计.md`

## 1. 验收范围

- Agent 页面成功提示不跨 `agent_id` 显示；
- Agent 页面局部错误、待确认计划和安装选择随 Agent identity 隔离；
- 同一 Agent 的后端业务状态仍由 props 和扫描结果驱动；
- 不修改 ownership、Connector 或 Agent 配置格式。

## 2. 自动化回归

回归测试位于：

- `apps/desktop/src/App.test.tsx`

测试链路：

1. 导航到 Claude Code；
2. 预览并确认恢复；
3. 等待“已恢复接入前的 Agent 配置”出现；
4. 导航到 OpenCode；
5. 确认 OpenCode 标题已出现；
6. 断言 Claude Code 的恢复提示不存在。

修复前该测试稳定失败，提示仍存在于 OpenCode 页面。
以 `metadata.agent_id` 作为 `AgentRoutePage` key 后测试通过。
