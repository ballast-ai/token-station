# 第二批协作任务：T2 配置漂移验收

> 日期：2026-07-22
> 范围：#2 配置指纹与三方漂移检测
> 结论：本地实现和自动化验收通过；真实 Agent 外部漂移人工冒烟留待最终总验收

## 1. 交付范围

- 后端以接管前加密快照、所有权记录中的最后写入 hash/HMAC、当前磁盘配置构成三方事实。
- 新增只读 `get_agent_drift(agent_id, installation_path)`，安装路径必须与最新扫描记录精确匹配。
- 状态覆盖 `in_sync`、`unowned_changes`、`managed_changes`、`missing`、`unreadable`、`unparseable`。
- 字段级结果只返回结构路径、受管范围和变化种类，不返回配置值。
- 前端展示“接管前 / 最后写入 / 当前磁盘”三列 hash、状态和变化路径，不提供自动覆盖动作。

## 2. 安全与边界证据

- 受管字段通过 HMAC 对账，不通过 IPC 暴露当前值或历史值。
- 非受管字段仅做结构化语义 diff；受管子树从普通 diff 中排除，避免重复或错误归类。
- 单次最多返回 200 条路径，超限显式设置 `truncated`。
- 路径输出移除控制字符并限制单段长度；内部所有权判断仍使用原始键名。
- 查询测试逐字节比较目标配置、ownership index 和 snapshot index，证明查询零写入。
- 当前配置缺失或不可解析时返回类型化状态，不创建、不修复、不覆盖文件。
