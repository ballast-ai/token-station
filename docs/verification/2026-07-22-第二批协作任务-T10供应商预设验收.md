## 3. 聚合边界与排除项

- `OpenRouter` 仍保留在 `AGGREGATOR_CANDIDATES`，不在 `PROVIDER_CATALOG`，添加页不会显示。
- Hugging Face Inference Providers Router 未收录，因为官方说明由服务端在多个 Provider 间选择。
- Anthropic 原生、Perplexity Agent API 因协议不匹配未收录；Azure/专属 Endpoint 因 URL 含用户部署占位符未收录。
- `managed_inference` 只表示供应商直接提供其托管推理 API，不表示 token-station 为其兼容性或模型权限背书。
