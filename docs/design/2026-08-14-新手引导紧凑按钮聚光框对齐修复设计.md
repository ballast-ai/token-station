# 新手引导紧凑按钮聚光框对齐修复

- 日期：2026-08-14
- 状态：部分实现；顶部添加供应商入口已修复，保存按钮仍有 7px 外扩
- 范围：首次配置引导的紧凑按钮聚光框几何

## 1. 问题、目标、范围和非目标

“添加供应商”属于紧凑按钮。当前聚光框统一在目标矩形外扩 7px 后绘制白色边框，导致边框与
按钮轮廓形成两个不重合的圆角矩形，视觉上像框体偏移或未对齐。

目标：紧凑交互控件的白色聚光边框与控件边界精确重合，遮罩开孔仍保留安全留白和外发光。

范围包含聚光框矩形计算及回归测试；不重排顶部导航、不修改按钮尺寸，也不重做教学卡片。

## 2. 安全与数据红线

1. 不自动点击目标、不改变教程进度和供应商数据。
2. 聚光遮罩不得拦截目标控件或暴露被遮挡区域的额外交互。
3. 不改变键盘焦点约束、Escape 暂停或 Tab 循环。

## 3. 用户可见交互、状态变化和失败处理

- 紧凑按钮：白色边框贴合真实按钮；信号色光环向外扩展。
- 大型配置区：继续保留 7px 呼吸空间，避免边框压住内容。
- 目标移动、缩放或响应式换行时，聚光框继续跟随 `ResizeObserver` 与滚动测量更新。

## 4. 响应式、键盘操作和可访问性

桌面和窄窗口均基于 `getBoundingClientRect()` 计算，不写死坐标。目标仍获得焦点和
`aria-describedby`；聚光框保持 `aria-hidden` 且不接收指针事件。

## 5. 公开测试边界、验收标准和真实 App 检查项

1. “添加供应商”目标矩形为固定测试值时，聚光边框的 top/left/width/height 必须与目标一致。
2. 路由配置等大型区域仍保持原有 7px 外扩行为。
3. 全量前端测试、构建、Rust workspace 测试和本地 App 安装通过。
4. 真实 App 中重新查看新手引导，确认“添加供应商”白框与按钮四边及圆角同心。

## 6. 实现落点与已知遗留项

- `apps/desktop/src/components/FirstRunGuide.tsx`：区分紧凑控件的 outline 与遮罩开孔矩形。
- `apps/desktop/src/components/FirstRunGuide.test.tsx`：锁定紧凑按钮精确对齐行为。

已知遗留：本次不建立像素级截图基线；几何测试覆盖定位，真实 App 检查覆盖渲染观感。
