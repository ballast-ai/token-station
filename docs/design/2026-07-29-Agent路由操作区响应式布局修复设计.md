# Agent 路由操作区响应式布局修复设计

## 问题与目标

Agent 路由卡片右侧同时放置状态说明、安装选择和多个操作按钮，但操作区固定 `max-width: 440px`，在桌面窗口中会把中文说明压缩成逐字竖排，并挤压按钮。目标是保持现有功能和顺序，让操作区在正常窗口横向排列、空间不足时自然换行，小窗口下改为纵向布局。

## 安全红线与范围

只调整桌面端 CSS 布局，不改变接管、恢复、重新扫描、强制断开等命令和配置写入逻辑；不改变按钮的禁用条件、键盘焦点顺序或文案。

## 用户可见行为、响应式与可访问性

状态说明至少保留可读宽度；操作按钮允许换行但不缩窄文字。窄窗口下身份信息和操作区上下排列，按钮保持可点击尺寸。所有现有按钮继续使用原生 `button`，不引入仅靠颜色表达状态的变化。

## 测试与验收

运行前端测试和桌面构建。真实 App 检查 Agent 路由页：中文状态说明不再逐字竖排，操作按钮不互相覆盖；缩小窗口后操作区能换行或纵向排列。

## 实现落点与发布要求

修改 `apps/desktop/src/App.css` 的 Agent 路由头部布局，完成测试后执行 `scripts/install-local-desktop.sh`，启动本地 App 验收，并用中文说明创建本地 commit。

## 实现状态

已完成 CSS 响应式修复；前端 24 个测试文件、197 项测试通过。修复版 `.app` 已重新编译、签名并启动；DMG 仍受本机 `bundle_dmg.sh` 失败影响，但不影响 App 本体运行。
