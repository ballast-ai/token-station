远程配置 Profile C2
新建 profile
四条口径：① 默认本地 — 客户端出厂只用本地 profile；② 显式开启 — 远程配置须在客户端主动订阅；③ 离线用缓存 — 断网时沿用最后一次拉取的版本；④ 随时回退 — 一条命令可切回本地 profile。

profile 只含非机密配置：路由规则、上游定义、配额。上游 BYOK key 只有引用名（如 upstream:anthropic-sub），key 本体永远在设备本地〔V2-NF-2，口径详见 自带上游〕。Preset 别名（如 @acme/code-review）建立在 profile 之上，见 预设 Preset。
