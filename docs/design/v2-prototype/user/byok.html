自带上游 BYOKP1

自带 provider key 或订阅凭证，由网关代你直连上游；模式与账路决定它和平台凭证的关系、以及钱从哪条路走。
口径说明：服务端 BYOK ≠ 客户端 BYOK P1

此处录入的 key 属于服务端 BYOK：由平台加密保管（仅存密文与校验哈希，不可回显），仅用于网关代你直连上游；决策记录只保存凭证归因，不保存凭证内容。

本地客户端（交付物①）的 BYOK key 永不上传云端：key 只存在你的设备上，云端配置 profile 中只有引用名——两者互不矛盾，请勿混淆隐私承诺的适用范围。本地客户端管理见 设备与客户端。
