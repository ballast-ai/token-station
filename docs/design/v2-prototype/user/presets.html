预设 PresetP4

一个 @preset/xxx 别名引用整套「模型 + 生成参数 + provider 偏好 + 路由策略」——改配置不改代码。
引用示例 P4
{ "model": "@acme/code-review", "messages": [...] }
在任意兼容 OpenAI 的 SDK 中，把 model 字段写成预设别名即可。团队改动预设配置（换模型、调参数、改路由策略）后所有引用方立即生效，无需改一行代码、无需重新发版。

与远程配置的关系 P4

预设建立在 P3 的 config profile（远程配置）之上：profile 解决「客户端从云端拉哪套连接配置」，preset 解决「一个别名代表哪套模型策略」。两者独立演进——

C2本地客户端的最小远程配置不要求 preset 别名：只拉 profile 里的网关地址与凭证引用名即可跑通（BYOK key 永不上传，只存本地）。
P4客户端若在请求里引用 @acme/code-review，别名在网关侧解析为当前版本配置，客户端无感知版本变化。
