# macOS 图标圆角修复设计

日期：2026-08-04
状态：已实现并通过安装包验收

## 问题与目标

Token Station 的 macOS 应用图标使用了四角铺满的 `icon.icns`。在 macOS Finder 和 Dock 中，它不像原生 Mac 应用那样显示圆角画布。
本次只修复 macOS 专用 `.icns`，保留通用 PNG、Windows ICO 和应用内部图标的现有行为。

## 用户可见行为

- macOS 图标使用 1024×1024 高分辨率画布。
- 原有 Token Station 标记保持原位、色彩和比例。
- 画布四角透明，外轮采用 macOS 常见的圆角方形，不给图标再叠加一层不属于原设计的阴影、高光或边框。

## 安全与范围

- 不改动业务代码、密钥、用户配置或其他平台图标。
- 只重建 `apps/desktop/src-tauri/icons/icon.icns`，不修改 `icon.ico` 和通用 PNG。
- 不将预览图标当成原始图层发布，不新增图标内容。

## 验收标准

1. `icon.icns` 可被 `iconutil` 解出为 macOS 图标尺寸集，包含 1024×1024 高分辨率资产。
2. 解出资产的四角为透明，圆角内部标记不被裁切。
3. 桌面端构建和产物审计通过，安装后检查 App 使用的 bundle icon。
4. 回写本文档的实现状态、实际检查结果和剩余限制。

## 实现落点

从现有 `icon.icns` 解出标准 iconset，对各个尺寸应用统一的圆角 alpha 掩膜，再使用 `iconutil` 重建 `.icns`。生成的中间 iconset 只保存在临时目录，不进入代码仓库。

## 验收结果

`scripts/install-local-desktop.sh` 已成功完成构建、产物审计、签名、精确替换和启动。从实际安装的
`/Applications/token-station.app/Contents/Resources/icon.icns` 解出后，得到 1024×1024 资产，四个角点 alpha 均为 0，并包含完整的 macOS 多尺寸 iconset。应用 bundle id 为 `com.tokenstation.desktop`，代码签名校验通过。

本次只更新 macOS `.icns`，通用 PNG 和 Windows ICO 保持不变。
