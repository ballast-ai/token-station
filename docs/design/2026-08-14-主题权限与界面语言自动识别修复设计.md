# 主题权限与界面语言自动识别修复设计

## 1. 问题、目标、范围与非目标

### 问题

1. Desktop 每次冷启动都会由 `ThemeProvider` 调用 Tauri 窗口 `setTheme`，但主窗口 capability
   没有授予 `core:window:allow-set-theme`。调用固定被 ACL 拒绝，统一 Toast 因此显示
   “界面主题已切换，但 macOS 外观没有完全同步”。重建必然触发冷启动，所以用户每次重建
   后都能看到。补齐权限后的真实冷启动还确认了第二个失败源：Dock 图标命令用 Objective-C
   对象指针相等判断 AppKit 是否应用图标；AppKit 可返回内容相同但对象地址不同的 `NSImage`，
   因此产生假失败。
2. 当前未保存语言偏好时固定使用英文，没有读取 macOS/WebView 提供的语言优先级。

### 目标

- 授予主窗口最小的 `set-theme` 权限，使现有主题同步调用真正可执行。
- Dock 图标设置后回读 AppKit 的有效图像状态，不再把对象地址或 AppKit 重编码后的 representation
  变化误判为同步失败。
- 没有有效已保存偏好时，按 `navigator.languages` / `navigator.language` 自动选择当前支持的
  界面语言。
- 用户手动选择的有效语言始终优先，不能被系统语言覆盖。

### 范围与非目标

范围包括 Desktop capability、语言初始化策略、公开测试和真实 App 验收。

当前完整产品文案只正式支持简体中文与英文；虽然翻译表中保留了未启用的繁体中文和日文
草稿，但大量页面仍使用中英双参数 `copy()`，不能据此宣称完整支持四种语言。本次只把
`zh-CN`、`zh-SG`、`zh-Hans` 和裸 `zh` 映射为简体中文；英文语言映射为英文；其他语言
按优先级继续寻找受支持语言，最终回退英文。不新增语言、翻译文案或“跟随系统”设置项。

## 2. 安全与数据红线

- 只新增 `core:window:allow-set-theme`，不扩大文件、网络、Shell、剪贴板或凭据权限。
- 语言识别只读取 WebView 的公开 locale 列表，不读取地区之外的用户数据，不联网、不遥测。
- 不修改供应商、模型、路由、Agent、API Key 或运行配置。

## 3. 用户交互、状态与失败处理

1. 首次启动/语言存储为空：读取浏览器语言优先级，选择第一个受支持语言。
2. 已保存 `zh-CN` 或 `en`：直接恢复保存值，系统语言不覆盖。
3. 兼容旧值 `zh`：继续按简体中文恢复。
4. 无受支持系统语言或读取失败：回退英文，App 继续启动。
5. 用户在设置中手动切换：沿用现有即时生效和持久化行为；写入失败时保留本次选择并显示
   现有错误 Toast。
6. 窗口主题与 Dock 图标仍分别执行；任一真实同步失败继续显示错误，不能静默吞掉。

## 4. 响应式、键盘与可访问性

不新增或移动控件，不改变断点、键盘路径和焦点。初始化后继续同步 `<html lang>`，确保
屏幕阅读器使用实际界面语言。

## 5. 公开测试边界与验收标准

- capability 静态测试确认主窗口明确包含 `core:window:allow-set-theme`，且没有宽泛权限扩张。
- 未保存偏好且系统首选 `zh-CN` / `zh-Hans` 时初始化为简体中文。
- 已保存英文时，即使系统首选中文也仍为英文。
- 不受支持语言能按 `navigator.languages` 顺序寻找英文/简体中文，全部不支持时回退英文。
- 原有手动切换、持久化失败、主题同步失败测试继续通过。
- 真实 App：重建冷启动后不出现主题同步 Toast；界面与 macOS 外观一致。语言自动识别通过
  隔离测试环境验证，真实用户现有语言偏好不得为验收而删除。

## 7. 实现与验收结果

- 主窗口已增加唯一所需权限 `core:window:allow-set-theme`；静态 capability 测试同时禁止
  `core:window:allow-set-*` 这类宽泛授权。
- Dock 图标回读从 Objective-C 指针相等收敛为 AppKit `NSImage.isValid()`：仍能拒绝解码失败、
  未保留或无效图像，但不再把 AppKit 复制/重编码图像误判为失败。
- 无有效保存偏好时，语言初始化按 `navigator.languages` 顺序解析；`zh-CN`、`zh-SG`、
  `zh-Hans`、裸 `zh` 自动选择简体中文，英文选择英文，其他语言最终回退英文。有效保存值
  继续最高优先。
- 定向测试：LanguageProvider 与 ThemeProvider 共 16 项通过；Dock 图标 4 项及 capability
  测试通过。
- 全量前端：35 个测试文件、375 项测试通过；TypeScript/Vite production build 通过，仅有
  既有的 chunk 大小提示。
- `cargo test --workspace --quiet` 最终全量通过；1 项既有真机只读用例按设计忽略。
- 最终 `scripts/install-local-desktop.sh` 完成隔离 bundled-plugin 门禁、release 构建、产物
  审计、ad-hoc 签名、固定 bundle id 替换和启动。
- 真实 `/Applications/token-station.app` 冷启动验收：左下“操作提示”为空，截图所示主题同步
  错误不再出现；界面保持已保存的简体中文。未删除或改写用户现有语言偏好，自动识别由隔离
  测试覆盖。
