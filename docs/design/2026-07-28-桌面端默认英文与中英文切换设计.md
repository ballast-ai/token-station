# 桌面端默认英文与中英文切换设计

- 日期：2026-07-28
- 状态：已实现并完成本机验收
- 范围：`apps/desktop`

## 1. 问题

桌面端已经有语言上下文和设置入口，但当前默认语言是简体中文，而且翻译只覆盖导航和部分设置。主页、供应商、Agent、用量、恢复页、错误反馈和可访问名称仍有中文硬编码。直接把默认值改成英文会形成中英混杂界面，不满足默认 UI 全英文的要求。

设置中还展示繁体中文和日语，但这两种语言没有覆盖当前完整桌面界面。继续展示不完整语言会让用户误以为所有页面都已本地化。

## 2. 目标

- 首次启动、清空语言偏好或遇到无效语言偏好时，默认使用英文。
- 默认英文覆盖桌面端所有用户可见页面、交互反馈、空状态、错误说明、占位文案、按钮和可访问名称。
- 设置中提供 English 和简体中文两种完整语言。
- 选择语言后立即应用，不需要重启 App。
- 用户选择写入本地存储，重新启动后恢复该选择。
- 现有旧值 `zh` 迁移为 `zh-CN`。

## 3. 范围

本轮覆盖以下桌面端表面：

- 全局导航、加载页、运行状态和全局反馈。
- 主页三档路由、策略、关键词、本地路由、请求记录和供应商目录。
- Agent 发现、连接、修复、断开和独立路由。
- 添加供应商、免费供应商接入、模型管理和价格编辑。
- 用量统计、预算、趋势图和请求日志。
- 设置、路由表、插件、外观、语言和关于页面。
- 安全恢复页和已知错误码说明。
- 键盘与屏幕阅读器使用的标签、标题和说明。

## 4. 非目标

- 不翻译供应商品牌核心名称、模型 ID、Agent 产品名、协议名、路径、命令、请求 ID 和错误码。供应商名称中的地区与产品类型说明随界面语言本地化。
- 不修改后端路由、供应商、Agent 接入或数据存储语义。
- 不在本轮提供繁体中文和日语。已有这两种旧偏好时回退到默认英文，避免显示部分翻译界面。
- 不根据操作系统语言自动选择界面语言。默认值固定为英文。

## 5. 红线

- 不读取或修改供应商 API Key。
- 不修改 `token-station.state.json`、路由草稿、Agent 配置或用户数据。
- 语言切换只能写入现有语言偏好键 `token-station-language`。
- 不把后端原始诊断、密钥、绝对路径或请求正文加入翻译资源。
- 不用运行时 DOM 替换或模糊字符串替换实现本地化。所有文案必须从明确的语言资源或组件语言接口产生。

## 6. 交互与状态

### 6.1 默认语言

语言偏好解析顺序固定为：

1. 本地存储为 `en` 时使用英文。
2. 本地存储为 `zh-CN` 或旧值 `zh` 时使用简体中文。
3. 其他值、空值和服务端渲染环境都使用英文。

首次渲染必须直接使用解析后的语言，不能先显示中文再切成英文。

### 6.2 设置入口

语言设置只展示两个单选项：

- English。
- 简体中文。

当前语言使用选中态和 `aria-checked=true` 表示。切换后立即更新：

- 当前页面文案。
- 左侧导航和顶栏。
- `document.documentElement.lang`。
- 本地存储。

### 6.3 文案规则

- 英文使用 sentence case，按钮使用明确动作。
- 中文使用简洁的产品语言，不逐字翻译英文句式。
- 产品名和工程标识保持原样，例如 Token Station、Agent、Provider、API Key、HTTP、SOCKS5。
- 带变量的反馈使用完整句子模板，禁止在组件内拼接可翻译片段。
- 后端返回的稳定错误码映射为本地化说明；未知错误保留诊断码，不伪造解释。

### 6.4 失败处理

- 本地存储不可用时仍使用英文，语言切换只影响当前会话。
- 翻译键缺失时开发和测试阶段应失败，不允许静默显示另一种语言或键名。
- 后端只返回原始字符串且没有稳定错误码时可以原样显示，但 App 自己产生的前缀、标题和操作建议必须本地化。

## 7. 响应式、键盘和可访问性

- 语言切换不得改变现有布局断点和控件尺寸。
- English 与简体中文选项都可用 Tab 聚焦、Enter 或 Space 选择。
- 所有图标按钮在两种语言下都保留可访问名称。
- 切换语言后焦点留在当前语言选项，不重置设置分区。
- 文案变长时允许省略的控件必须保留完整 `title` 或可访问名称。
- `prefers-reduced-motion` 行为不因语言切换改变。

## 8. 公开测试边界

测试只通过公开界面观察行为：

1. `LanguageProvider`：无偏好时默认 `en`，同步文档语言并持久化。
2. `LanguageProvider`：恢复 `zh-CN`、迁移旧值 `zh`，无效值回退英文。
3. `App`：默认首页、导航、主要操作和状态文案为英文，不出现已知中文主界面文案。
4. `App`：从 Settings 选择简体中文后，主页、导航和设置同步切换并持久化。
5. 页面和组件测试：高风险交互继续验证对应语言的按钮、空状态、错误和可访问名称。

不测试翻译对象内部结构，不对整个页面创建脆弱快照。

- 本地安装脚本成功完成构建、审计、签名校验、精确替换和启动。

## 11. 发布要求

任何影响界面或可执行行为的改动，交付前必须执行：

```bash
scripts/install-local-desktop.sh
```

只允许替换 bundle id 为 `com.tokenstation.desktop` 的 `/Applications/token-station.app`。构建或审计失败时保留当前已安装 App。

## 12. 已知遗留项

- 生产主包仍有超过 500 kB 的现有 Vite 警告，本轮不处理分包。
- 后端少数无结构化错误码的原始错误字符串暂时无法可靠本地化，后续应补充稳定错误契约。
