# Cursor 会员提示与钥匙串授权修复设计

## 问题

Cursor 原生 Agent 的第三方模型入口受 Cursor 会员权限限制。当前页面没有持续说明该条件，未开通相应权限的用户可能在接入失败后才知道限制。

Token Station 写入 Cursor SecretStorage 前，需要通过 macOS 登录钥匙串读取 `Cursor Safe Storage`。首次由 Token Station 访问时，macOS 会要求用户授权。当前后端把授权取消和读取失败压成通用错误，页面只能显示“操作未能完成”。

## 目标

- Cursor 页面始终显示“仅 Cursor 付费会员可接入”。
- 钥匙串没有授权时，错误信息说明授权用途，并提示用户在 macOS 对话框中选择“始终允许”后重试。
- 保留 Cursor 官方 BYOK 接入方式，不继续尝试修改 Cursor 本体或绕过会员限制。

## 范围

- 调整 Cursor 页面标题区的固定提示。
- 调整 `Cursor Safe Storage` 读取失败时的后端错误。
- 增加页面测试和后端错误文案测试。

## 非目标

- 不修改 Cursor 可执行文件、签名、运行参数或会员状态。
- 不向免费账户开放 Cursor 原生 Agent 的第三方模型入口。
- 不自动更改 macOS 钥匙串访问控制。

## 安全与数据边界

- Token Station 不保存 `Cursor Safe Storage` 主密码。
- 错误信息不得包含钥匙串输出、密钥内容或用户密码。
- 用户拒绝授权时，Cursor 数据库不得写入新配置，已启动的临时隧道必须关闭。

## 用户可见行为

1. Cursor 标题旁固定显示“仅 Cursor 付费会员可接入”。
2. 首次接入触发 macOS 钥匙串授权属于正常流程。
3. 用户取消授权或读取失败时，Toast 提示：首次接入需要授权 Token Station 读取 `Cursor Safe Storage`，请选择“始终允许”后重试。
4. 其他 Cursor 状态和恢复流程保持不变。

## 可访问性与响应式

- 会员提示使用文字表达，不依赖颜色。
- 提示在窄窗口中允许换行，不遮挡状态和操作按钮。
- 现有按钮名称和键盘操作保持不变。

## 验收标准

1. Cursor 未接入、已接入和需修复时都能看到会员提示。
2. 模拟钥匙串读取失败后，页面显示具体授权说明，不显示通用错误。
3. 钥匙串错误不包含系统命令输出或任何秘密值。
4. Cursor 页面目标测试和后端目标测试通过。
5. 本地桌面 App 已更新，真实页面能看到会员提示。

## 实现位置

- `apps/desktop/src-tauri/src/cursor_tunnel.rs`：生成不泄露敏感信息的钥匙串授权错误。
- `apps/desktop/src/pages/AgentRoutePage.tsx`：显示 Cursor 固定会员提示。
- `apps/desktop/src/pages/AgentRoutePage.test.tsx`：覆盖固定提示和接入错误。
- `apps/desktop/src/App.css`：控制提示布局。

## 发布要求

改动完成后运行 Cursor 相关目标测试，并通过 `scripts/install-local-desktop.sh` 更新本机桌面 App。真实验收不点击接入按钮，避免在 Cursor 运行期间改写配置。

## 实现与验收结果

- Cursor 标题区已经固定显示“仅 Cursor 付费会员可接入”。
- `Cursor Safe Storage` 读取失败已经改用专用错误。页面会提示用户输入本机登录密码，并在 macOS 对话框中选择“始终允许”。
- `AgentRoutePage.test.tsx` 的 17 项测试已经全部通过。
- Rust 钥匙串错误目标测试已经通过，确认错误信息没有包含命令输出。
- `scripts/install-local-desktop.sh` 已经完成桌面门禁测试、前端生产构建、App 审计、签名、安装和启动。
- 已安装 App 的 Cursor 页面已经显示会员提示。验收期间没有点击重新接入，因此没有触发钥匙串授权，也没有改写 Cursor 配置。
