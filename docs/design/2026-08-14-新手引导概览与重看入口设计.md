# 新手引导概览与重看入口设计

## 1. 问题与事实核对

当前首次设置引导直接从“添加供应商”开始，覆盖供应商、路由和 Agent 接入，但没有解释
“概览”页的用途。应用已经在“设置 → 关于”提供“重新查看新手引导”按钮，现有引导却只在
旧设计文档中记录该路径，真实教程文案没有告诉用户。

因此本轮不是新增第二个教程入口，而是补齐教程的信息架构：先认识概览，再进入配置任务，
并在教程内明确现有重看入口。

## 2. 目标、范围与非目标

### 目标

1. 新手引导每次打开时先展示真实概览页，说明代理状态、当前路由、请求成本和接入规模。
2. 概览教学文案明确说明左上角 Token Station 标志是概览入口。
3. 概览教学文案和完成态均明确说明可从“设置 → 关于 → 重新查看新手引导”再次打开。
4. 已经看过旧版引导的用户能够看到本次新增内容。

### 范围

- `FirstRunGuide` 新增概览微步骤和中英文文案。
- `OverviewPage` 暴露稳定、语义化的引导目标。
- 首次自动打开和“关于”页手动重开均先进入概览步骤。
- 完成态补充重看路径，并升级引导版本标记。
- 增加组件级与 App 级公开行为测试。

### 非目标

- 不重做概览页布局、数据口径或快捷操作。
- 不移动“重新查看新手引导”按钮，也不新增常驻悬浮入口。
- 不改变供应商、路由、Agent 的真实配置动作和完成判定。
- 不新增后端命令、远端文档链接或网络请求。

## 3. 安全与数据红线

- 概览引导只解释现有只读数据，不读取、复制、展示或记录 API Key、提示词、响应正文和请求 body。
- 不因进入概览或继续教程触发保存、应用路由、接入 Agent、启动代理或外网请求。
- `localStorage` 仍只保存引导版本；不保存用户处于哪一页、配置状态或教程完成时间。
- 引导目标继续使用稳定的 `data-onboarding-target`，不依赖可变文案、DOM 下标或 CSS 层级。

## 4. 用户可见交互与状态变化

### 4.1 首次打开或手动重开

1. 应用完成本机 Agent 启动扫描后，如需展示教程，先导航到真实“概览”页。
2. 聚光灯保留概览内容可见，教学卡说明：
   - 概览用于快速查看代理运行状态、路由、请求与成本、Agent 和供应商规模；
   - 点击左上角 Token Station 标志可随时返回概览；
   - 需要重看教程时，前往“设置 → 关于 → 重新查看新手引导”。
3. 用户点击“开始配置”后回到主页，并按现有真实状态进入供应商、路由、Agent 或完成步骤。

### 4.2 中止、跳过与完成

- “稍后继续”只关闭本次教程，不写入已结束状态；下次启动仍会从概览开始。
- “不再提示”沿用现有语义，写入新版本标记并关闭教程。
- 配置完成弹窗保留当前状态总结，并增加重看路径。
- 已完成全部配置的用户重开教程时仍先看概览，再进入“首次设置已完成”，不会重复配置。

### 4.3 失败处理

- 概览目标尚未挂载时，沿用“正在定位操作位置…”等待状态；目标出现后恢复“开始配置”。
- 概览统计读取失败不阻塞教程；页面按现有独立降级文案显示。
- `localStorage` 不可写时，教程仍可关闭，不阻塞 App。

## 5. 视觉、响应式与可访问性

### 5.1 设计方向

- **对象**：本地 AI Agent 和模型路由控制台；面向需要配置供应商与 Agent 的研发用户。
- **单一任务**：让用户先建立“概览负责观察、主页负责配置”的心智模型。
- **颜色**：沿用现有 `--canvas`、`--surface`、`--ink`、`--muted`、`--signal`，不引入新色。
- **字体**：标题与正文沿用 IBM Plex Sans，步骤标签沿用 IBM Plex Mono。
- **布局**：沿用 360px 聚光灯卡片，不新增大模态或插画。
- **标志性元素**：真实概览数据位于聚光灯开孔内，教学卡悬浮其上；用户看到的是自己的系统，不是静态教程截图。

```text
┌ Token Station ─ 主页 供应商 用量 设置 ───────────────┐
│ ╔══════════════ 真实概览页（聚光灯内）════════════╗ │
│ ║ 概览                                             ║ │
│ ║ [代理状态] [今日成本] [Agent] [供应商]            ║ │
│ ║          ┌──────────────────────────┐             ║ │
│ ║          │ 先看概览                 │             ║ │
│ ║          │ 用途 + 重看路径          │             ║ │
│ ║          │              [开始配置]  │             ║ │
│ ║          └──────────────────────────┘             ║ │
│ ╚══════════════════════════════════════════════════╝ │
└──────────────────────────────────────────────────────┘
```

自检：没有增加通用欢迎页、渐变英雄区或装饰性步骤条；新增结构仅服务于 Token Station 的
“观察 → 配置”路径，避免与当前紧凑控制台风格冲突。

### 5.2 响应式与键盘

- 复用现有聚光灯卡片定位：窄屏或低窗口自动收敛到可视区并允许卡片内部滚动。
- Tab 焦点仍限制在当前目标和教学卡操作；概览根目标可由引导临时获得焦点。
- Escape 等同“稍后继续”，关闭后焦点回到左上角 Token Station 概览按钮。
- `prefers-reduced-motion` 和强制色模式沿用现有规则；不新增必须播放的动画。

## 6. 公开测试边界与验收标准

### 组件公开行为

1. `microStep="overview"` 显示“先看概览”、概览用途和完整重看路径。
2. 概览目标未挂载时不显示“开始配置”；挂载后可点击并触发继续回调。
3. 完成弹窗在接入 Agent 和跳过 Agent 两种状态下都显示重看路径。

### App 公开行为

1. 未看过新版教程时，启动后先显示“概览”页面和“先看概览”教学卡，不直接显示“添加你的第一个供应商”。
2. 点击“开始配置”后回到主页，并按现有状态进入正确的配置步骤。
3. 从“设置 → 关于”点击“重新查看新手引导”后同样先进入概览步骤。
4. 新版本标记使旧版 `spotlight-setup-v1` 记录不再抑制教程。
5. “不再提示”、Escape、真实保存应用与 Agent 接入的原有行为保持不变。

### 真实 App 检查项

- 深色模式下概览页真实数据可见，遮罩、聚光灯开孔和教学卡没有裁切或层级错误。
- 教学卡文案完整显示“设置 → 关于 → 重新查看新手引导”。
- “开始配置”进入主页；从“设置 → 关于”可再次回到概览教程。
- 键盘 Tab、Shift+Tab、Escape 可用，焦点恢复正确。

## 8. 实现状态与验收结果

### 已实现

- 引导版本升级为 `spotlight-setup-v2`；只看过 v1 的用户会看到新增内容。
- 首次自动打开和“关于”页手动重开都会先进入真实概览页，并高亮完整概览内容区。
- 概览步骤说明页面用途、左上角 Token Station 概览入口，以及
  “设置 → 关于 → 重新查看新手引导”的重看路径。
- 概览聚光灯开孔增加透明交互阻挡；真实数据保持可见，但下层快捷操作不会抢走点击和键盘焦点。
- “开始配置”回到主页并恢复现有的真实状态推荐步骤；两种配置完成态均重复说明重看路径。
