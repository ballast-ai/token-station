# 首次进入聚光灯引导设计

- 日期：2026-08-10
- 状态：已实现并验收；2026-08-10 按反馈将教程重开入口调整至“关于”页
- 原型来源：`apps/desktop/prototypes/first-run-onboarding-prototype.html?variant=b`
- 正式范围：`apps/desktop`

## 1. 问题

Token Station 首次打开后直接进入概览。新用户可以看到供应商、路由、Agent 和运行状态，但缺少一条
明确且符合依赖关系的起步路径。已验证的操作顺序是：

```text
添加供应商 → 配置并保存应用路由 → 接入 Agent
```

旧原型曾把“启动代理”放在添加供应商之前。该顺序不成立：没有可用供应商与已应用路由时，代理进程
即使运行也不能完成有效模型转发。

## 2. 目标

1. 本地数据目录中的首次 App 会话，在真实状态加载并渲染概览后自动展示三步聚光灯引导。
2. 聚光灯依次指向真实“添加供应商”、“路由”和“检查 Agent 接入”控件。
3. 通过短文案说明依赖顺序，不在引导内伪造连接、保存、应用或 Agent 接入操作。
4. 用户关闭、跳过或完成后不再自动展示；设置页允许随时重新查看。
5. 保持当前 Token Station 的 IBM Plex、语义色、紧凑桌面密度、明暗主题和中英文能力。

## 3. 范围与非目标

### 3.1 范围

- 新增生产组件 `FirstRunGuide`。
- 为三个真实控件增加稳定的 `data-onboarding-target` 定位属性。
- 使用版本化、非敏感的 `localStorage` 标记记录已关闭状态。
- 在“设置 → 关于”增加“重新查看新手引导”入口。
- 覆盖自动展示、步骤顺序、关闭持久化、设置重开、键盘和窄窗口布局。

### 3.2 非目标

- 不把引导改成强制配置向导；“下一步”不调用任何写操作。
- 不自动添加供应商、选择模型、保存路由、启动代理或修改 Agent 配置。
- 不新增 Rust/Tauri command、配置字段、数据库迁移或网络请求。
- 不根据按钮点击次数伪造真实步骤完成状态。
- 不删除原型；原型继续作为方案选择的历史证据保留在独立分支历史中。

## 4. 安全与数据红线

- 引导不读取、展示、复制或传输 API Key、虚拟 Key、提示词、响应正文或请求 body。
- 持久化值只包含引导版本和“已关闭”状态，不包含供应商、模型、Agent、运行态或时间戳。
- 底层页面在引导打开时不可交互，避免用户误触真实写操作。
- 文案明确：配置路由后需要“保存并应用”；只有真实运行状态显示成功才代表路由可用。
- 不改变现有 Provider 回收站、Agent 快照/补丁、Revision 或代理生命周期语义。
- `localStorage` 读写失败不得阻断 App；读取失败时本次会话不自动弹出，写入失败时仅保证当前会话关闭。

## 5. 用户可见交互与状态

### 5.1 自动展示

- App 的 `StateView`、Registry 和概览 DOM 已就绪后读取引导标记。
- 当前版本标记不存在时，从概览页第一步自动打开。
- 标记值为当前版本时不自动展示。
- 新版本若需要重新教学，必须显式提升版本常量；不能因普通文案或 CSS 更新骚扰用户。

### 5.2 三步顺序

#### 第一步：添加供应商

- 聚光灯目标：顶部“添加供应商”按钮。
- 标题：先添加一个模型供应商。
- 说明：选择供应商、填写凭据并先运行连接测试；不暗示当前已经连接成功。

#### 第二步：配置并启动路由

- 聚光灯目标：顶部“路由”一级导航。
- 标题：配置并启动路由。
- 说明：为上、中、下三档选择模型并点击“保存并应用”；真实代理状态变为运行中后才可用。

#### 第三步：接入 Agent

- 聚光灯目标：概览“检查 Agent 接入”快捷操作。
- 标题：接入你的第一个 Agent。
- 说明：扫描已安装 Agent、检查配置变更预览、明确确认后接入。

### 5.3 按钮与关闭

- “下一步”推进一步；第二、三步显示“上一步”。
- 第三步主按钮为“完成引导”。
- “跳过引导”、关闭按钮、Escape 和完成均写入当前版本标记并关闭。
- 点击遮罩不关闭，防止误触导致永久跳过。
- 关闭后焦点返回始终存在的 Token Station 概览入口，避免设置页按钮因页面已切回概览而失去焦点目标。

### 5.4 关于页重新查看

- “设置 → 关于”在版本与更新区域展示“新手引导”和“重新查看”按钮；通用页不再展示该入口。
- 点击后先返回概览，再从第一步打开。
- 重新查看不清除已关闭标记，因此下次启动仍不会自动弹出。

### 5.5 失败处理

- 目标控件暂未渲染时，卡片居中展示且不渲染错误位置的聚光灯；DOM 更新或窗口变化后重新测量。
- `localStorage` 读取异常：不自动弹出，App 继续使用。
- `localStorage` 写入异常：关闭当前会话引导，不显示错误横幅，不影响其他设置。
- ResizeObserver 不可用时退化到窗口 resize 和步骤切换测量。

## 6. 视觉与动效

### 6.1 设计 Token

- 画布、文字、边框、主色和暗色主题全部复用 `App.css` 现有语义变量。
- 标题/正文使用 IBM Plex Sans；步骤编号使用 IBM Plex Mono。
- 引导卡片复用 shadcn/Radix Dialog 语义与现有 Button、Progress。
- 不新增第二套色板、字体或组件库。

### 6.2 识别性元素

唯一强视觉元素是与真实控件尺寸一致的聚光灯框。框外使用半透明遮罩，框内保留原页面亮度；引导卡片
根据目标位置放在下方或左侧，不使用装饰性插画、渐变大标题或无业务意义编号。

### 6.3 动效

- 打开时遮罩和卡片淡入，步骤变化时聚光灯在 180–240ms 内移动。
- `prefers-reduced-motion: reduce` 时关闭位移和缩放，仅保留即时状态变化。

## 7. 响应式、键盘与可访问性

- 1040×720：卡片不遮挡当前目标，三个真实控件均可识别。
- 900×600：聚光灯仍定位真实目标；空间不足时卡片居中并限制最大高度，内容可滚动。
- Dialog 使用 `aria-modal=true`、可见 `DialogTitle` 和 `DialogDescription`。
- 打开时焦点进入卡片；Tab 只在卡片内循环。
- Escape 关闭并记录；关闭后恢复焦点。
- 进度使用 `Progress`，具有当前步骤的可访问名称和值。
- 图标按钮具有中英文 `aria-label`；图标来自项目 Lucide 配置。
- 聚光灯本身 `aria-hidden=true`，辅助技术通过标题、描述和进度获取同等信息。

## 9. 公开测试边界

测试只通过用户可观察接口断言，不测试测量函数、内部 state 名称或 CSS 实现：

1. 未有当前版本标记时，真实状态加载后自动出现“先添加一个模型供应商”。
2. “下一步”依次出现“配置并启动路由”和“接入你的第一个 Agent”。
3. 每一步的目标元素都带当前步骤可观察的高亮标记。
4. 跳过、关闭、Escape 和完成后写入标记；重新挂载不再自动出现。
5. 已有标记的普通用户不出现引导，现有导航和操作不受影响。
6. “设置 → 关于”的“重新查看新手引导”返回概览并打开第一步，但不删除标记；通用页不存在该按钮。
7. 中英文文案、Dialog 标题、进度和关闭按钮均可被可访问查询找到。
8. 存储异常不阻断 App 渲染。

## 12. 实现与验收回写

- 实现状态：已完成。生产组件使用版本 `b-v1` 的非敏感本地标记，接入真实供应商、路由和
  Agent 快捷操作锚点；“设置 → 关于”提供重开入口，通用页不再显示该按钮。引导只解释步骤，
  不调用 Tauri 写命令。
- 公开行为测试：新增首次自动展示、依赖顺序、目标切换、跳过持久化、设置重开和 Escape/焦点
  恢复场景，均经历 red → green。真实 App 验收时发现 shadcn `Progress` 封装未向 Radix Root
  传递值，已补可访问语义测试并修复。
- 自动化结果：`npm run test -- --run` 为 28 个文件、256 条测试全通过；`npm run build` 通过，
  仅有既存的大 chunk 提示；根工作区与桌面壳层的 `cargo fmt`、`cargo clippy -D warnings`、
  `cargo test` 全通过。桌面壳层为 254 条通过、1 条只读环境烟测按定义忽略。
- 本地 App 安装：移动入口后的首次安装在 LaunchServices 启动阶段返回 `-600`，脚本按事务语义
  自动恢复旧版本；确认 bundle id 与签名正常后重试成功。最终隔离门禁测试、前端构建、release
  bundle、bundle id、代码签名、制品审计和启动均通过，安装位置为 `/Applications/token-station.app`。
- 真实界面验收：1040×720 浅色 App 中三步分别准确包围“添加供应商”、“路由”和“检查 Agent
  接入”；通用页没有教程入口；关于页在“检查更新”旁显示“重新查看新手引导”，点击后返回概览
  并从第一步重开。完成后焦点回到“Token Station 概览”，重启后不再自动展示。900×600 主界面
  无横向溢出，卡片 CSS 具备视口夹取、最大高度和滚动退化。
- 已知验收遗留：最终一轮 900×600 重开弹窗和深色主题的鼠标验收因用户正在操作同一 App 而
  未继续争用；相关响应式、语义色和 reduced-motion 规则已进入构建，发布前仍建议补一次人工
  截图复核。这不影响已验证的首次展示、顺序、持久化和键盘核心路径。
- 产品遗留：本轮不根据 Provider、Route 或 Agent 的真实完成状态自动跳步；若后续升级为配置
  向导，必须另行设计状态机与失败恢复。
