# develop 分叉合并与交付加固设计

- 日期：2026-08-11
- 状态：实现与本地验收完成
- 目标分支：`develop`
- 实现分支：`codex/develop-merge-hardening-20260811`
- 关联设计：[`首次配置聚光灯任务向导设计`](2026-08-10-首次配置任务向导升级设计.md)

## 1. 问题

本地 `develop` 与 `origin/develop` 已分别产生首次配置向导和错误本地化、桌面图标、发布门禁等改动，
双方共同修改了桌面入口与供应商页面。直接合并会在 `App.tsx` 产生内容冲突；即使机械解决冲突，
本地公开测试仍断言原始英文后端错误，与远端“按当前语言显示可行动错误”的契约冲突。

合并前审查还发现四类公开行为缺口：目标临时不存在时仍可能显示推进操作；路由成功门禁没有显式要求
`running_revision === saved_revision`；Agent 扫描失败后可能错误开放“暂不接入”；路由阶段的全局滚动
拦截会连教学卡片内部滚动一起阻止。

发布差异中还记录了本机绝对路径。工作区另有一份未跟踪调研文档，不属于本次发布，必须留在本机。

## 2. 目标

1. 在独立分支合并 `origin/develop`，保留双方有效行为并消除冲突。
2. 修复上述公开行为缺口，用用户可观察的 UI 和既有 IPC 返回建立回归测试。
3. 用户可见错误按当前语言解释“发生了什么、下一步怎么做”，不直接展示任意后端字符串。
4. 本次发布差异中所有人工维护的源码注释使用英文。
5. 删除发布文档中的本机绝对路径，不提交未跟踪调研、配置、凭据、缓存、日志或构建目录。
6. 通过全量自动化、本地桌面 App 安装和真实界面检查后，创建中文提交并合并到远端 `develop`。

## 4. 安全与数据红线

- 未跟踪文件默认视为用户本地数据；只允许按明确路径暂存本设计列出的交付文件。
- 发布差异不得包含真实用户主目录、系统临时目录、真实凭据、Authorization header 或本机恢复路径。
- 错误格式化不得把任意后端原文、文件路径、事务快照或密钥带回 UI；未知错误使用安全兜底。
- 合并、提交、推送和 PR 都使用精确分支与精确文件路径；禁止 `git add .`、`git add -A` 或模糊删除。
- 本地 App 安装仍只允许替换 bundle id 为 `com.tokenstation.desktop` 的固定应用路径。

## 5. 用户可见行为与失败处理

### 5.1 临时缺失的聚光灯目标

- 当前微步骤声明了真实目标但目标尚未挂载、尺寸为零或刚切页时，教学卡片显示“正在定位操作位置”。
- 定位完成前不显示会推进微步骤或跳过 Agent 的操作；暂停与“不再提示”仍可用。
- 目标出现后恢复原说明、焦点和允许的真实操作，不自动推进。

### 5.2 路由权威运行态

显式“保存并应用”后，仅在以下条件全部成立时进入 Agent：

- `app_runtime === "running"`；
- `listener_reachable === true`；
- `serve.error === null`；
- `running_revision === saved_revision === 本次目标 revision`；
- `config_dirty === false` 且 `config_error === null`。

任何 revision 不一致、启动失败、监听不可达或配置仍脏都停留在“保存并应用”。

### 5.3 Agent 扫描与跳过

- 只有最近一次扫描成功、结果为空且当前不在扫描中时，才显示“暂不接入，完成设置”。
- 扫描失败或返回 `scan_in_progress` 时不沿用旧的“空结果成功”资格；页面保留重试入口和人话错误。
- 扫描成功发现安装时进入 Agent 选择，不提供伪完成路径。

### 5.4 滚动行为

- 路由 `2/4`—`4/4` 继续锁定主工作区，防止聚光灯目标漂移。
- 教学卡片内部和显式教学浮层允许滚动；滚动卡片不改变主工作区锁定位置。
- Escape、暂停、卸载或离开路由步骤时立即解除监听。

### 5.5 错误提示与注释语言

- Provider 保存等应用错误继续进入共享本地化格式化器；已知错误说明原因和处理建议，未知错误使用安全兜底。
- 中文界面不显示原始英文后端错误，英文界面不混入中文后端错误。
- 本次发布差异中人工编写或修改的源码注释统一为英文；协议名、类型名、命令、错误码和专有名词保留原文。

## 6. 响应式、键盘与可访问性

- 等待卡片沿用现有 `dialog` 标题关系，并用可见文字说明等待状态；不得只用空聚光框表达。
- 目标未就绪时 Tab 只进入教学卡片的暂停和“不再提示”；目标出现后恢复真实目标与卡片的焦点圈。
- 900×600 下等待文案、卡片操作和目标恢复后的位置不得横向溢出或遮挡目标。
- 教学卡片滚动放行不得放开卡片外页面控件，也不得改变 Escape 语义。

## 7. 公开测试边界与验收标准

公开测试只观察真实 DOM、可访问名称、真实按钮、工作区滚动和既有 IPC mock，不读取组件内部 state。
按垂直切片执行：

1. 目标缺失时先观察推进按钮仍存在的红测；实现后只显示等待状态，目标挂载后恢复操作。
2. `running_revision` 等于目标但 `saved_revision` 不同的红测必须停留在路由；三者一致才推进。
3. Agent 扫描失败的红测不得出现跳过；随后成功空扫描才允许跳过。
4. 教学卡片 wheel 事件红测应被放行，同时主工作区 wheel 仍被取消。
5. Provider 保存失败公开测试断言当前语言的人话错误，而不是原始后端字符串。
6. `git diff --check`、前端全量测试与构建、Rust fmt、Clippy、workspace 测试和桌面 Rust 门禁通过。
7. 发布差异通过本机路径、凭据模式、未跟踪文件和生成垃圾审计。
8. 执行 `scripts/install-local-desktop.sh`，完成构建、审计、签名、固定路径安装与启动。
9. 真实 App 至少复查首次引导等待/目标恢复、路由聚光灯滚动、中文错误样式及应用启动。
