文档

Token Station 的完整 API 参考。所有端点采用统一的身份验证方式：Authorization: Bearer gw-YOUR_KEY。参见所有支持的模型。

通用端点（兼容 OpenAI）

这些端点接受 OpenAI 格式的请求，适用于所有提供商。只需修改 model 字段即可切换提供商——网关会自动完成格式转换。

以下三个端点对所有 LLM 提供商通用。先列出 OpenAI 风格的端点，再列出对应的 Anthropic 端点：

端点方法描述
/v1/chat/completionsPOSTOpenAI Chat Completions——适用于所有 LLM 提供商，支持流式响应。
/v1/responsesPOSTOpenAI Responses API——无状态模式适用于所有 LLM 提供商。有状态的推理连续性（跨轮次保留的 encrypted_content / Anthropic thinking 块）仅在原生支持该特性的提供商上有效——请在模型列表中查看 Stateful 标记。
/v1/messagesPOSTAnthropic Messages API——适用于所有 LLM 提供商。Anthropic 与 Claude Code 的原生流量按字节原样透传；其他提供商的流量经转换后以 Anthropic SSE 形式返回。
/v1/images/generationsPOST图像生成——OpenAI DALL-E、Gemini Imagen、xAI Grok、Bailian Wan 2.7、MiniMax image-01
/v1/video/generationsPOST视频生成——Gemini Veo、Kling、Bailian Wan、BytePlus Seedance、MiniMax Hailuo、xAI Grok
/v1/audio/speechPOST文本转语音——OpenAI、Groq、xAI、MiMo、Bailian Qwen3-TTS、MiniMax Speech
/v1/audio/transcriptionsPOST音频转录——OpenAI、Groq、ElevenLabs
/v1/audio/translationsPOST音频翻译——OpenAI、Groq
/v1/music/generationsPOST音乐生成——MiniMax music-2.6（完整歌曲 / 纯器乐）

聊天补全

适用于所有 LLM 提供商。设置 "stream": true 即可启用流式响应。

curl -X POST http://GATEWAY/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer gw-YOUR_KEY" \
  -d '{
    "model": "openai/gpt-5.4",
    "messages": [
      {"role": "system", "content": "You are helpful."},
      {"role": "user", "content": "Hello!"}
    ],
    "max_completion_tokens": 1024,
    "stream": true
  }'

更改模型名称即可切换提供商：

    "n": 1
  }'

视频生成

统一的 /v1/video/generations 端点在内部完成异步轮询——只需发送一次请求，视频就绪后即可拿到视频 URL。适用于所有视频提供商。

音频

TTS（文本转语音）

# OpenAI TTS
curl -X POST http://GATEWAY/v1/audio/speech \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer gw-YOUR_KEY" \
  -d '{
    "model": "openai/tts-1",
    "input": "Hello, world!",
    "voice": "alloy"
  }' --output speech.mp3

# Bailian Qwen3-TTS (returns wav)
curl -X POST http://GATEWAY/v1/audio/speech \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer gw-YOUR_KEY" \
  -d '{
    "model": "bailian/qwen3-tts-flash",
    "input": "Hello, world!",
    "voice": "Cherry"
  }' --output speech.wav

# MiniMax Speech (mp3 by default; wav/flac/pcm via response_format)
curl -X POST http://GATEWAY/v1/audio/speech \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer gw-YOUR_KEY" \
  -d '{
    "model": "minimax/speech-2.6-turbo",
    "input": "Hello, world!",
    "voice": "Wise_Woman",
    "response_format": "wav"
  }' --output speech.wav

OpenAI：openai/tts-1、openai/tts-1-hd、openai/gpt-4o-mini-tts

Groq：groq/orpheus-v1-english、groq/orpheus-arabic-saudi

Bailian：bailian/qwen3-tts-flash、bailian/qwen3-tts-instruct-flash（音色：Cherry、Ethan、Serena 等——OpenAI 音色名称会统一映射为 Cherry）

MiniMax：minimax/speech-2.8-hd、-2.8-turbo、-2.6-hd、-2.6-turbo、-02-hd、-02-turbo（音色：Wise_Woman、English_Graceful_Lady 等——OpenAI 音色名称会统一映射为 Wise_Woman；mp3/wav/flac/pcm）

ASR（转录）

curl -X POST http://GATEWAY/v1/audio/transcriptions \
  -H "Authorization: Bearer gw-YOUR_KEY" \
  -F file=@audio.mp3 \
  -F model=openai/gpt-4o-transcribe

OpenAI：openai/gpt-4o-transcribe、openai/gpt-4o-mini-transcribe、openai/gpt-4o-transcribe-diarize、openai/whisper-1

Groq：groq/whisper-large-v3、groq/whisper-large-v3-turbo

ElevenLabs：elevenlabs/scribe-v2（自动由 OpenAI 格式转换）

音乐

音乐生成 (MiniMax)

同步生成完整歌曲 / 纯器乐 / 翻唱。统一路由返回一个 JSON 信封，音频以 base64 编码存放在 data[0].b64_json 中，并附带 extra_info（时长、采样率、比特率）。按每次生成统一计费。

模型：minimax/music-2.6。格式：mp3（默认）、wav、pcm。按每次生成统一计费（$0.15/首，最长 5 分钟）。

提供商原生端点

这些端点直接使用提供商自身的 API 格式——不做任何转换。当你需要某个提供商的特有功能时，请使用它们。

Anthropic Messages API

curl -X POST http://GATEWAY/v1/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer gw-YOUR_KEY" \
  -d '{
    "model": "anthropic/claude-sonnet-4-6",
    "max_tokens": 1024,
    "system": "You are helpful.",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'

WASM 中间件

API 密钥可以绑定 WASM 中间件模块，在转发请求前对其进行拦截和改写。请在控制台中选择预设模块，或上传你自己的模块。

内置模块：

模块描述
Complexity Router基于 10 维请求分析，自动路由到低价 / 中端 / 高端模型
Echo Redirect模板——原样回显请求体，并重定向到固定模型

身份验证

所有 API 请求都需要提供网关密钥：Authorization: Bearer gw-YOUR_KEY

网关在向上游转发时会注入对应提供商的认证请求头——你的请求中无需携带任何提供商的 API 密钥。

JSON API

端点方法描述

/api/keysPOST创建新的 API 密钥
