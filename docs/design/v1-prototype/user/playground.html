流式
用户
用一句话解释什么是向量嵌入？
助手
向量嵌入是把文本、图像等内容映射成一串数字（高维向量）的技术，语义相近的内容在向量空间中彼此靠近，从而支持相似度搜索、聚类和推荐等任务。
用户
帮我写一个通过这个网关调用嵌入接口的 Python 示例。
助手
当然，直接用 requests 即可——网关兼容 OpenAI 格式： import requests r = requests.post( "https://models.bytefuture.ai/v1/embeddings", headers={"Authorization": "Bearer gw-YOUR_KEY"}, json={ "model": "gemini/gemini-embedding-001", "input": "你好，向量嵌入", }, ) print(r.json()["data"][0]["embedding"][:8]) 把 model 换成任何目录里的嵌入模型即可，无需改动其他代码。
Cmd/Ctrl+Enter 发送 · 仅多模态模型支持附件
请求 
# POST /v1/chat/completions · streaming

  -H "Authorization: Bearer gw-•••" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "openai/gpt-5.5",
  "messages": [
    {
      "role": "user",

    },
