# Gate B / T3：端点解析与能力诚实设计

> 日期：2026-07-22
> 范围：Provider 最终 URL、模型能力四态、同步语言模型边界；不包含 Agent Skill 用量与异步媒体任务。

## 1. 不变量

1. Provider URL 只能由 `ProviderEndpoint` 解析；adapter 不再手写字符串拼接。
2. origin、API root（如 `/v1`、`/api/v4`）和完整 endpoint 三种输入必须归一为同一 API root，不能生成 `/v1/v1`。
3. `unknown` 和 `unsupported` 都不得当成支持；只有 `declared` 与 `verified` 可以进入相应语言模型能力路由。
4. `verified` 表示真实请求验证过，不是供应商宣传或名称猜测；测试必须让 verified tool 能力完成一次真实代理请求。
5. image、audio、embedding 都在上游调用前以 `ErrorCode::Capability` 拒绝，统一说明“本代理只路由语言模型”。即使配置把 vision 写成 verified，也不能越过产品边界。

## 2. Endpoint 解析

协议层新增三种目标：

- Chat Completions：`chat/completions`
- Responses：`responses`
- Messages：`messages`

`ProviderEndpoint::try_new` 识别完整 endpoint 后剥离末尾目标段，保存 API root；`resolve(target)` 只在一个地方拼接最终 URL。origin 输入默认使用 `/v1`，非空自定义 root（如 `/api/paas/v4`）原样保留。

桌面端通过只读 Tauri command 调同一解析器，在保存前显示 Chat / Responses / Messages 三条最终 URL。解析失败显示明确错误且不允许保存。

## 3. 能力四态

`CapabilityState` 为闭集：`verified / declared / unsupported / unknown`。v1 ABI 的 `tool / vision / json_schema` bool 保留，避免旧 Provider plugin 无法读取新配置；并行增加可选的 `*_state` 证据字段：

- `*_state` 存在时以四态为准；
- 旧 `true` 且无 state → `declared`；
- 旧 `false` 且无 state → `unsupported`；
- 新配置若证据未知，显式写 `*_state: unknown`。

兼容桥遵守两条规则：host 传给 v1 plugin 前，把显式 state 投影回 bool（`verified/declared=true`，`unknown/unsupported=false`）；plugin 返回后，仅在它未返回显式 state 时恢复配置证据，不能覆盖新版 plugin 的显式判断。Router 只接受 `verified/declared`。桌面新建或发现的模型没有能力证据，三项能力均显式写 `unknown`；只有真实探测或人工声明才能升级。Provider 视图保留模型 ID 列表，并新增逐模型的 tool / vision / JSON Schema 状态标签，避免破坏现有选择器接口。

## 4. 同步语言模型边界

embeddings 依据规范化路径在 Agent adapter 匹配前拒绝，任何旧版或第三方 adapter 都不能抢先 claim。其余媒体语义在 gateway 已完成 JSON 解析、但调用 Agent adapter 和 Router 前检查；只检查顶层 `modalities/audio`、`messages[*].content/audio` 与 Responses `input/content` 等协议字段，不递归扫描 metadata、扩展字段、工具 schema 或 prompt 文本：

- content item `image_url` / `input_image`
- content item `input_audio` / `audio` / `audio_url`
- `/v1/embeddings` 或等价 embeddings 路径

命中后 attempts 必须为 0，receipt 的 `error_code=capability`。这条 host 级边界高于模型 capability 声明，防止错误配置把同步网关伪装成多模态或异步任务系统。

## 5. 验收

1. 三种 base URL 输入对三种目标各自解析为唯一正确路径。
2. Provider 编辑页保存前展示三条后端解析的最终 URL；非法 URL 禁止保存。
3. bool 旧配置可迁移，四态序列化稳定，unknown 不路由。
4. verified tool 模型完成真实 tool 请求。
5. vision、audio、embedding 请求均得到 typed Capability，0 次上游调用，不等待超时。
