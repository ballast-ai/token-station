# Cursor 隧道版本界面阻断与主题同步修复设计

日期：2026-08-14
状态：实现中

## 1. 问题

Cursor 公网隧道版本已经实现受控 HTTPS 入口、Safe Storage 密钥写入和配置恢复，真实 App 仍有两项界面问题：

1. Cursor 使用独立数据库接入，不依赖普通 Connector 唯一绑定。页面仍把 `CONNECTOR_BINDING_NOT_UNIQUE` 判定为“暂不可接入”，导致可用的一键接入被错误状态覆盖。
2. 主窗口调用 Tauri 原生主题同步时缺少 `core:window:allow-set-theme` 权限，启动后显示“界面主题已切换，但 macOS 外观没有完全同步”。
3. `cloudflared` 发布包大于 `ureq` 默认的 10 MiB 响应上限，首次下载会在解压前失败。
4. Quick Tunnel 已经注册边缘连接，但本机 DNS 无法解析随机 `trycloudflare.com` 域名。现有代码要求本机请求该域名成功，因此错误关闭了 Cursor 云端本可访问的隧道。
5. Dock 图标更新后使用 Rust 指针地址比较 AppKit 返回的 `NSImage`。AppKit 保留或复制图像时地址会变化，成功更新也会被报告为失败。
6. Cursor 3.15 已改用 `aiSettings.userAddedModels`、`modelOverrideEnabled` 和 `modelConfig` 保存自定义模型。现有代码只写旧版 `availableAPIKeyModels`，因此隧道成功后仍看不到 `tokenstation/auto`。

Cursor 运行中返回的 `cursor_running` 也会被转换成通用错误，用户无法看到需要彻底退出 Cursor 的实际处理方法。

## 2. 目标与范围

- Cursor 发现结果为 `CONNECTOR_BINDING_NOT_UNIQUE` 时，页面继续显示可接入状态，并使用专用数据库和隧道流程。
- `cursor_running` 在中英文界面显示明确退出提示，保持 Cursor 运行时拒绝写入的安全限制。
- 主窗口获得原生主题同步所需的最小 Tauri 权限。
- `cloudflared` 下载使用高于固定发布包大小的有限上限，并继续校验长度和 SHA-256。
- 参考 MIT 许可的 Ungate 实现启动 Quick Tunnel。cloudflared 返回 HTTPS URL 且进程继续运行后即可写入 Cursor 配置，不再要求本机解析随机域名。
- cloudflared 显式使用空配置文件和 IPv4 Edge，避免用户已有 ingress 配置干扰 Quick Tunnel。
- Dock 图标更新只验证 AppKit 保留了应用图标，不再依赖对象地址相同。
- 同时维护 Cursor 新版 `aiSettings` 模型字段和旧版 `availableAPIKeyModels`，接入时选中 `tokenstation/auto`。
- 保留现有 Cursor 公网隧道、临时令牌、路径白名单、Safe Storage 和恢复逻辑。

本轮不修改 WorkBuddy usage、Platform Gates 或供应商路由，也不自动关闭 Cursor。

## 3. 安全与数据边界

- Cursor 运行状态检查继续发生在数据库写入前。
- Cursor 原始 `applicationUser` 继续完整备份。断开接入时恢复原文，避免遗留模型选择或覆盖用户配置。
- 不读取或输出 Cursor 密钥、Token Station 虚拟 Key 和供应商凭据。
- Tauri capability 只增加主窗口主题设置权限。
- 公网桥接继续只接受 Cursor 临时令牌和既有白名单路径。

## 4. 用户可见结果

- Cursor 未接入时显示“可接入”，不再显示 Connector 唯一绑定错误。
- Cursor 运行时点击一键接入会显示完整退出提示，按钮随后恢复可用。
- macOS 原生窗口主题同步成功后，不再显示主题权限错误。
- Quick Tunnel 地址返回后直接进入接管状态。真实可用性由 Cursor 云端请求和 Token Station 请求记录验证。
- Cursor 隧道接入成功后继续显示“已接入”和“恢复官方配置并断开”。
- Cursor 启动后显示并选中 `Token Station Auto`，真实 Agent 请求使用该模型进入 Token Station。

## 5. 实现位置

- `apps/desktop/src-tauri/capabilities/default.json`：增加主题设置权限。
- `apps/desktop/src/components/ThemeProvider.test.tsx`：锁定 capability 合同。
- `apps/desktop/src/errors.ts` 和 `errors.test.ts`：增加 `cursor_running` 映射。
- `apps/desktop/src/pages/AgentRoutePage.tsx`：允许 Cursor 独立数据库接入，并统一显示结构化错误。
- `apps/desktop/src/pages/AgentRoutePage.test.tsx`：覆盖可接入状态和运行中提示。
- `apps/desktop/src-tauri/src/cursor_tunnel.rs`：限制 `cloudflared` 下载大小，使用 Ungate 的 Quick Tunnel 启动参数，取消本机 DNS 健康检查，并兼容 Cursor 新旧模型字段。
- `apps/desktop/src-tauri/src/lib.rs`：删除 Dock 图标更新后的指针相等判断。

## 6. 验收标准

1. 主题 capability 测试通过。
2. 错误映射和 AgentRoutePage 定向测试通过。
3. Cursor tunnel Rust 测试通过。
4. Desktop production build 和本地 App 安装审计通过。
5. 真实 App 不再显示主题权限错误，Cursor 页面显示“可接入”。
6. Cursor 退出后可以启动一键接入，页面切换为“已接入”。
7. 本地缓存的 `cloudflared 2026.8.0` 可以建立 Quick Tunnel，并在日志中完成边缘连接注册。
8. Cursor 真实请求抵达 Token Station 后，才能确认云端链路可用。
9. 数据库测试确认 `tokenstation/auto` 已写入新版模型列表和现有模式，恢复后 `applicationUser` 与原值完全一致。

## 7.1 参考实现

- Ungate：<https://github.com/orchidfiles/ungate>，MIT License。
- 采用其 `--config /dev/null`、`--edge-ip-version 4` 和“收到 Tunnel URL 后进入运行状态”的做法。
- 不引入 Ungate 扩展、OAuth 代理或运行时数据库写入；Token Station 继续使用现有桥接、临时令牌和恢复机制。

## 7. 实现与验收记录

真实 App 已确认页面状态修复和主题 capability 已进入安装包。首次一键接入暴露了 `ureq` 10 MiB 下载限制。后续独立诊断确认 cloudflared 已注册 QUIC 边缘连接，随机 Quick Tunnel 域名却在本机连续 45 次解析失败。Ungate 源码表明成熟实现不做本机 DNS 健康检查，而是在取得 Tunnel URL 后进入运行状态。主题切换误报来自 Dock 图标的指针相等判断。最终实现和真实 Cursor 请求验收将在调整完成后继续回写。
