# 全 Agent 图片与视觉附件降级设计

## 1. 问题、目标、范围和非目标

Agent 会把历史消息中的图片与当前文字一起发给 Token Station。当路由池只有纯文本模型时，现有能力门会在上游请求前返回 HTTP 400。这会让一个无关的旧图片阻断当前的文字、文件路径和工具调用。

本次目标是为所有 Agent 建立统一的视觉降级：

1. 存在支持视觉的可选模型时，保留完整图片并按原规则路由。
2. 原请求仅因图片或视觉附件无法满足能力门时，把 Canonical IR 中的图片块替换为本地化文本占位，然后重新路由。
3. 中文对话使用中文占位，英文及其他对话使用英文占位。
4. 模型继续处理其余文字、文件路径和工具结果，而不是由 Token Station 伪造一条 assistant 答复。

本次不把音频、embedding、任意未知附件或上游认证错误改成文本。不自动切换用户选定的模型，也不声称纯文本模型看到了被省略的图片。

## 2. 安全与数据红线

1. 降级只改写内存中本次请求的 Canonical IR，不改 Agent 历史、本地附件或用户配置。
2. 占位符不包含图片 URL、base64、文件名或其他正文，Receipt 仍不落请求正文。
3. 只替换已规范化为 `ContentPart::ImageUrl` 的图片块。未知块、文档正文、音频、tool call 和 tool result 不得静默删除。
4. 只在原路由失败是 `Capability/Vision`，或上游用明确、已脱敏的错误摘要拒绝图片时重试。认证、限流、容量、JSON Schema、tools 和上下文长度错误保持原样。

## 3. 用户可见交互、状态与失败处理

英文对话中，每个被替换的图片块成为：

```text
[Image omitted: the current model does not support visual input.]
```

中文对话中，每个被替换的图片块成为：

```text
[图片已省略：当前模型不支持视觉输入。]
```

语言根据当前请求最后一条含文字的 user 消息判断；存在中文字符时选中文，其余选英文。占位符作为请求内容发给真正模型，用户最终看到的是模型根据剩余内容生成的回答。

如果替换后仍无法路由，Token Station 返回第二次的真实 typed error，不伪造成功。

## 4. 响应式、键盘与可访问性

本次不新增 UI 控件或布局，因此无新的响应式和键盘交互。占位符是普通文本，屏幕阅读器可按对话内容读取，不依赖颜色或图标传达状态。

## 5. 公开测试边界、验收标准和真实 App 检查

1. OpenAI 协议的 WorkBuddy、OpenCode 和 Hermes 在纯文本路由上都继续请求上游。
2. 中文最后 user 文本产生中文占位，英文产生英文占位。历史图片同样被替换。
3. 只有图片而没有文字时使用英文占位，请求仍可达上游。
4. 有视觉候选时，上游收到原始图片块，不发生占位。
5. 音频、embedding、tools、JSON Schema 和认证错误仍按原设计拒绝。
6. 降级成功的 Receipt 记录真实上游尝试和 200 结果，不再记成 attempts=0 的假成功。
7. 完成全量测试和构建后运行 `scripts/install-local-desktop.sh`，在真实 App 检查 Agent 页面、代理运行状态和一次中英文降级请求。
8. `--local` 构建只产生安装所需的 macOS `.app`，不制作用于发布的 DMG；`--production` 仍按发布配置生成全部 bundle。这避免本地安装被无关的 Finder/DMG 打包失败阻断。
9. PR 提交前运行仓库 Rust 格式检查和 `cargo clippy --workspace --all-targets -- -D warnings`。媒体重试保持独立函数边界，不得让主 `dispatch()` 超过 Clippy 的行数门禁。

## 6. 实现落点、遗留项和发布要求

`apps/cli/src/gateway.rs` 在 Agent 完成 inbound normalize 后处理 Canonical IR。路由器先评估原请求；若唯一未满足要求是 Vision，Gateway 复制请求、本地化占位并重新路由。Anthropic native passthrough 在目标模型明确不支持视觉时应用等价的 JSON 块替换；能力未知时仍 fail open，保持 passthrough 协议保真。若已选上游在 HTTP 400/415/422/501 的脱敏错误摘要中明确拒绝 image、vision、media 或 attachment，Gateway 对同一上游最多降级重试一次，并把两次尝试都记入 Receipt。

本次不建立按模型名称猜测的全局名单。Token Station 已有 `vision_state` 证据模型，应优先使用明确的 `declared/verified/unsupported/unknown` 状态。已知遗留项是 Anthropic native passthrough 的能力未知模型仍 fail open；为保持原始协议错误语义，该路径尚未对上游拒绝执行第二次 passthrough 请求。

发布前必须回写实现状态、公开测试、真实 App 验收和遗留项，然后使用中文提交说明创建本地 commit。
