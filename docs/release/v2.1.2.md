# Token Station v2.1.2

This release fixes image input routing and adds explicit checks for Provider vision support.

## Image input and routing

- Preserve images throughout request routing. Channels that reject image input return an explicit error without retrying a text-only request.
- Preserve native Responses conversation history across JSON and streaming image requests.
- Keep free requests on free fallback channels and honor text-based routing rules for image requests.

## Vision verification and feedback

- Test a configured model with a generated image and show its result next to that model.
- Keep verification progress and feedback when model management closes and reopens.
- Bind verification results to the configuration, plugin content, and credentials used by that check.
- Apply saved vision capabilities to the running proxy without restarting a proxy that the user has stopped.

## Update and installation

Supported macOS builds can select **Check for Updates** to install v2.1.2. Windows and Linux updates are manual from the GitHub Release page.

The macOS Apps use Developer ID signatures and Apple notarization.
The Windows MSI is not Authenticode-signed and can show an unknown publisher warning.
Verify manual downloads with the published `SHA256SUMS` file.
