# Token Station v1.3.3

This preview hardens usage accounting, model testing, and release validation. It also improves the desktop
usage and routing interfaces.

## Usage and cost accuracy

- Anthropic native requests now preserve upstream token reports across buffered, streamed, retried, and
  client-disconnected attempts. A stream that ends without the required terminal event is marked as
  truncated instead of being reported as complete.
- The usage view distinguishes canonical input totals from older upstream-reported input values. Historical
  rows no longer imply a precision that the stored data does not contain.
- Cache-write token counts and cache pricing remain explicit through aggregation, display, and catalog
  refreshes. A partial catalog response cannot silently replace a more complete cached price record.
- Usage refresh and repricing avoid rewriting incompatible historical rows. Request details show the source
  and quality of the token values used for cost calculations.

## Desktop workflow improvements

- The usage page places its summary and trend controls in the first viewport. It adds clearer request,
  token, cache, success-rate, and cost context.
- Usage tabs support keyboard navigation and keep focus aligned with the selected view.
- Model tests now use the same routing, quota, retry, cancellation, and receipt control plane as normal
  requests. The desktop keeps one gateway generation active during a test session.
- Agent routing and Provider controls use clearer labels, tighter layouts, and larger navigation targets.

## Reliability and release safeguards

- Official Provider fixture packs now include provenance checks and packaged conformance coverage.
- CI separates pull-request, main, platform, and release gates. A version tag fails closed when the exact
  commit has not passed the required checks.
- Release builds verify their source mode, package inventory, updater assets, and current architecture
  record before publication.
- Windows desktop lint now keeps Unix-only security test helpers out of Windows test builds.
- The CLI and desktop backend are split into smaller control-plane and command modules without changing the
  public configuration format.

## Update and installation

An installed preview can select **Check for Updates** and confirm the v1.3.3 update. The updater verifies the
signed payload before installation.

For a manual installation, download `token-station_1.3.3_aarch64_UNSIGNED-UNNOTARIZED.dmg` and its
`.sha256` file. Verify the checksum, drag the App to Applications, and follow the README in the DMG if macOS
blocks it.

This preview supports Apple Silicon only. The DMG and App are ad-hoc signed, unsigned by Apple, and not
notarized. The updater signature protects the update payload, but it does not provide Apple Developer ID
identity or an Apple notarization ticket.
