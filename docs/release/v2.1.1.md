# Token Station v2.1.1

This stable release improves Agent model routing, request inspection, and usage accounting. It also fixes
Agent discovery and configuration recovery across supported platforms.

## Agent routing and compatibility

- Codex and Claude Code can select Token Station models with route-specific context limits, while Codex
  preserves full-access and compaction behavior.
- OpenClaw refreshes credentials in its active runtime catalogs, and WorkBuddy discovery follows the active
  bundled runtime after an upgrade.
- Agent configuration changes reject stale previews and preserve newer edits during recovery. The Cursor
  connection entry has been removed.

## Request inspection and providers

- Request logs show HTTP details, and model tests retain request information for troubleshooting.
- Direct route selection keeps provider and model choices together, while navigation warns about unapplied
  route changes.
- Native Responses forwarding, web search, and Gemini tool schemas preserve more provider capabilities
  across supported Agent connections.

## Usage and reliability

- Usage accounting handles stream cancellation and late completion more consistently, with clearer
  separation of request usage and cost annotations.
- Pricing controls and usage charts improve model lookup, filtering, and time-bucket presentation.
- Agent model guides and actionable error details clarify setup and recovery, while dependency updates
  address known vulnerabilities.

## Update and installation

Existing supported macOS builds can select **Check for Updates** and install v2.1.1. Windows and Linux
updates are manual from the GitHub Release page.

The macOS Apps use Developer ID signatures and Apple notarization. The Windows MSI is not Authenticode-signed and can show an unknown publisher warning.
Verify manual downloads with the published `SHA256SUMS` file.
