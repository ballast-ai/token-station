# Token Station v2.0.0

This stable release expands Token Station to Windows and Linux. It also redesigns Agent routing and provider
management while preserving the local security boundary.

## Cross-platform desktop support

- macOS packages support Apple Silicon and Intel. Windows receives an x86-64 MSI. Linux receives x86-64
  AppImage, Debian, and RPM packages.
- Closing the main window keeps Token Station running when a native tray is available. A second launch
  restores the existing process instead of creating another gateway owner.
- Agent discovery uses bounded native install locations without executing a user shell. Cursor remains
  connectable only on macOS.

## Agent routing and providers

- Agent configuration previews show the exact planned changes before Token Station writes a supported Agent
  configuration. Recovery rejects stale operations and preserves newer user changes.
- Managed and direct routing use one route workspace. Provider and model selectors show the active route
  context without duplicating local-only controls.
- Enterprise providers can expose their available models and maintain managed routes without changing local
  provider credentials.

## Reliability and security

- Native status actions use the same generation-checked gateway lifecycle on every platform. Stale Start and
  Stop actions cannot replace a newer state.
- Sensitive Agent configuration values stay behind explicit reveal actions. Logs and error paths keep the
  existing secret-redaction boundary.
- Release checks require four CLI archives, both macOS architectures, the Windows MSI, all three Linux
  packages, updater signatures, and complete SHA-256 checksums.

## Update and installation

Existing supported macOS builds can select **Check for Updates** and install v2.0.0. Windows and Linux
updates are manual from the GitHub Release page.

The macOS Apps use Developer ID signatures and Apple notarization. The Windows MSI uses Authenticode. Verify
manual downloads with the published `SHA256SUMS` file.
