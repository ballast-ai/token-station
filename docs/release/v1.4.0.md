# Token Station v1.4.0

This preview adds desktop packages for Windows and Linux while preserving the existing macOS menu bar and
update behavior.

## Desktop platform support

- macOS packages now cover Apple Silicon and Intel. Windows receives an x86-64 MSI. Linux receives x86-64
  AppImage, Debian, and RPM packages.
- Closing the main window keeps Token Station running when a native tray is available. A second launch
  restores the existing process instead of creating another gateway owner.
- Windows uses a notification-area tray icon. Linux uses its native tray menu when the desktop environment
  provides one.

## Agent and lifecycle compatibility

- Windows and Linux Agent discovery uses bounded native install locations without executing a user shell.
  Cursor remains connectable only on macOS.
- Native status actions now use the same generation-checked gateway lifecycle on every platform. Stale Start
  and Stop actions cannot replace a newer state.
- Startup and recovery paths no longer depend on macOS-only listener or menu state.

## Release validation

- Windows validation runs the complete Rust and desktop suites, builds two MSIs, and tests install, launch,
  upgrade, downgrade refusal, and uninstall behavior.
- Linux packages are built on Ubuntu 22.04 and audited for the bundled official adapters and local-data
  protections.
- The preview asset check requires both macOS architectures, the Windows MSI, all three Linux packages,
  updater signatures, and complete SHA-256 checksums.

## Update and installation

Existing supported macOS previews can select **Check for Updates** and confirm the v1.4.0 update. Windows and
Linux updates are manual from the GitHub Release page.

This is an unsigned cross-platform preview. The macOS Apps use ad-hoc signatures and are not signed or
notarized by Apple. The Windows MSI has no Authenticode signature and can show a SmartScreen warning. Linux
packages are unsigned. Verify the published SHA-256 checksums before manual installation.
