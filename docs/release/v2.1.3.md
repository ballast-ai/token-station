# Token Station v2.1.3

This release improves image routing, Agent connection controls, and desktop startup.

## Image input and routing

- Try eligible channels with unknown image support without requiring a manual verification first. Keep images intact through fallback attempts.
- Distinguish image capability refusals from policy, credential, quota, and image-format errors. Retain support learned from successfully delivered responses.
- Keep the selected Direct model and provide an explicit shortcut to a verified image model on the same channel.

## Agent connections and desktop

- Keep managed Agent configuration visible while the proxy is stopped. Start the proxy explicitly before previewing a connection.
- Delete ordinary encrypted backups after seven days while preserving pinned recovery baselines. Show backup status accurately before applying changes.
- Show the desktop build identity and restore the fixed 2.7-second launch animation, with immediate error feedback and reduced-motion support.

## Update and installation

Supported macOS builds can select **Check for Updates** to install v2.1.3. Windows and Linux updates are manual from the GitHub Release page.

The macOS Apps use Developer ID signatures and Apple notarization.
The Windows MSI is not Authenticode-signed and can show an unknown publisher warning.
Verify manual downloads with the published `SHA256SUMS` file.
