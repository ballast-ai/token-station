# Token Station v2.2.0

This release adds subscription plan channels and managed web search, and moves the provider engine to South
0.85.1.

## Subscription plans

- Connect ChatGPT, Codex, Claude, GitHub Copilot, Gemini CLI and Antigravity plans as native channels. A unified
  subscription window manages them.
- Route by plan quota, and keep each provider's own limits.
- Discover local Codex installations at startup, including Codex inside the ChatGPT macOS App. Reuse local Codex
  sessions.

## Web search

- Prefer a provider's native web search, and fall back to a bounded local search.
- Add Tavily as a managed search backend, plus an opt-in headless browser search preview.
- Enforce domain filters, queue concurrent browser searches, and require retrieved evidence for search-only
  requests.
- Record search credits separately from model usage.

## Routing and Agents

- Add an optional Jev cloud tier and a persistent local classification switch.
- Support several enterprise endpoints.
- Scope fallback scoring for narrow tasks and continuations.
- Expose Token Station Auto in Codex and the Token Station model in Claude Code. Fix discovery and connection
  recovery for OpenClaw, WorkBuddy, OpenCode and Claude.
- Route image requests without a manual vision verification first.

## Provider engine (South 0.85.1)

- Anthropic routes now send the client's `thinking` mode and budget upstream, and replay signed thinking across
  tool turns on Anthropic and GitHub Copilot.
- Usage is exact or the request fails.
  - A buffered OpenAI-compatible, ChatGPT, Codex, Copilot Responses or Gemini plan response with missing,
    incomplete or inconsistent usage now returns `502 provider_protocol_error` instead of recording zero tokens.
    Streamed responses without usage are still accepted.
  - Local search rounds and model checks are buffered requests, so the same rule applies to them.
- Anthropic cache tokens are counted once, and Claude plan input now includes its cache tokens.
- Azure OpenAI requests send the output limit as `max_completion_tokens`.
- Gemini's OpenAI-compatible key shape (`authorization` together with `x-goog-api-key`) uses the South transport.
- Components built before the South range handshake are refused at load with a named reason. Every bundled
  component uses the new handshake.

## Desktop

- Simplify the settings, routing, model and usage pages, and refine the request log audit view.
- Show actionable errors, keep Agent discovery non-blocking at startup, and expire Agent backups after seven days.

## Security and dependencies

- Update Rustls, chacha20 and other vulnerable dependencies, and bound HTML parsing and stream parsing work.

## Update and installation

Supported macOS builds can select **Check for Updates** to install v2.2.0. Windows and Linux updates are manual
from the GitHub Release page. Verify manual downloads with the published `SHA256SUMS` file.
