# token-station v1.1.3

v1.1.3 是稳定的源码 Release，并附带 Apple Silicon 未签名测试 DMG。

## 改进

- **首次配置更稳定**：修复向导等待目标、步骤修订门禁、Agent 扫描时机和聚光灯滚动残影，页面状态变化后不会停在错误步骤。
- **报错更容易理解**：面向用户的失败提示会直接说明问题和下一步，不再只显示内部错误码或工具原始输出。
- **发布边界更严格**：新增版本一致性、正式资产白名单和 macOS DMG 安全门禁，未配置正式签名时不会输出可能被误认为正式版的二进制。
- **macOS 支持边界对齐**：App bundle 的最低系统版本校正为 macOS 11.0。
- **DMG 恢复标准拖拽安装**：沿用 v1.1.2 的 128 px 主图标关系，把 App 与 `Applications` 放在同一行，并把安装与安全说明整齐放在下方。

- **源码**：GitHub 自动生成的 `zip` 和 `tar.gz` 归档

> 该 DMG 未签名、未公证、仅供测试。Apple 没有验证开发者身份，Gatekeeper
> 会拦截首次打开。请先核对 `.sha256`，再阅读 DMG 内的 `安装前必读.md`。
> 不要为安装该测试包全局关闭 Gatekeeper。

本次不提供 CLI 二进制或应用内更新载荷。

Release 只引用已合并的远端提交，不包含开发机配置、凭据、Token、用户名路径或未跟踪文件。
