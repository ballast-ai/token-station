# Token Station v1.2.3

This Apple Silicon preview corrects enterprise managed routing and hardens the local preview release process.

## Enterprise managed routing

- Enter a Base URL, API key, and optional account name, then use one **Connect and use** action.
- Token Station validates the managed endpoint without saving its real model catalog.
- The desktop stores only the `auto` alias. The enterprise service selects the real model and owns routing policy.
- Provider creation and the Direct route target now form one backend draft change.
- Image, tool, structured-output, and reasoning requirements pass through to the managed route.
- The App reports terminal apply success only after the saved revision is running.

The bilingual enterprise gateway contract is available in `docs/guides/enterprise-managed-routing.md`.

## Update and installation

An installed v1.2.1 preview can check for v1.2.3 and install it inside the App. The updater verifies the signed
payload before installation.

For a new installation, download `token-station_1.2.3_aarch64_UNSIGNED-UNNOTARIZED.dmg` and its `.sha256`
file. Verify the checksum, drag the App to Applications, and follow the README in the DMG if macOS blocks it.

This preview supports Apple Silicon only. The DMG and App are ad-hoc signed, unsigned by Apple, and not
notarized. The updater signature protects the update payload, but it does not provide Apple Developer ID
identity or an Apple notarization ticket.
