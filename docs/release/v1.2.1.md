# Token Station v1.2.1

This preview release establishes the Apple Silicon in-app update channel.

## Update behavior

- One click checks for an update and opens the install confirmation when one exists.
- The App downloads only after confirmation.
- Tauri verifies the update signature before the local gateway stops.
- The App installs the verified payload and restarts.
- The update manifest uses a dedicated preview channel.

## Bootstrap installation

The v1.2.0 App does not contain the updater public key. Install v1.2.1 manually once. Later preview versions
can update inside the App.

Download `token-station_1.2.1_aarch64_UNSIGNED-UNNOTARIZED.dmg` and its `.sha256` file. Drag the App to
Applications. Open the concise English README if macOS blocks the App.

This DMG and App are ad-hoc signed, unsigned by Apple, and not notarized. The updater signature protects the
update payload. It does not provide Apple Developer ID identity or an Apple notarization ticket.

This pre-release supports Apple Silicon only. It does not provide Intel macOS, Windows, Linux, CLI binaries,
or a formal stable update channel.

# Token Station v1.2.1（简体中文）

此预发布版建立 Apple Silicon 应用内更新通道。

## 更新行为

- 点击一次即可检查更新。发现更新后，App 会直接打开安装确认。
- 用户确认后，App 才会下载更新。
- Tauri 会先验证更新签名，然后才停止本地网关。
- App 会安装已验证的更新并自动重启。
- 更新清单使用独立的预览通道。

## 引导安装

v1.2.0 App 没有内置更新公钥。请手动安装一次 v1.2.1。后续预览版可以在 App 内直接更新。

请下载 `token-station_1.2.1_aarch64_UNSIGNED-UNNOTARIZED.dmg` 和对应的 `.sha256` 文件。把 App 拖到
Applications。如果 macOS 阻止 App，请打开精简的英文 README。

此 DMG 和 App 使用 ad-hoc 签名，没有 Apple 签名，也没有 Apple 公证。更新器签名可以保护更新包
完整性，但不能提供 Apple Developer ID 身份或 Apple 公证票据。

此预发布版仅支持 Apple Silicon。它不提供 Intel macOS、Windows、Linux、CLI 二进制或正式稳定
更新通道。
