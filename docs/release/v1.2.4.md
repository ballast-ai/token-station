# Token Station v1.2.4

This Apple Silicon preview adds complete Japanese and Traditional Chinese interfaces.

## Japanese and Traditional Chinese

- Select English, Simplified Chinese, Traditional Chinese, or Japanese in Settings.
- Navigation, setup, routing, usage, errors, recovery actions, status messages, and accessibility text now use the selected language.
- New installations detect supported Japanese and Chinese browser locales. Existing valid language choices remain unchanged.
- Dynamic provider, model, route, quota, and receipt details keep their values while using locale-specific grammar and formatting.

## Update and installation

An official v1.2.3 preview can check for v1.2.4 and install it inside the App. The updater verifies the signed
payload before installation.

If the App says that the current build does not include the official updater public key, install v1.2.4
manually once. Later official previews can update inside the App.

For a manual installation, download `token-station_1.2.4_aarch64_UNSIGNED-UNNOTARIZED.dmg` and its `.sha256`
file. Verify the checksum, drag the App to Applications, and follow the README in the DMG if macOS blocks it.

This preview supports Apple Silicon only. The DMG and App are ad-hoc signed, unsigned by Apple, and not
notarized. The updater signature protects the update payload, but it does not provide Apple Developer ID
identity or an Apple notarization ticket.
