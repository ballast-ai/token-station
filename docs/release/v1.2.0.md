# Token Station v1.2.0

This source pre-release adds a polished macOS drag-to-Applications package for Apple Silicon. It also includes
the product changes made after v1.1.3.

## Highlights

- Prioritizes connected Agents on the overview.
- Adds model-centered Agent routing and route previews.
- Adds provider model search, batch price import, and refreshed model catalogs.
- Adds enterprise endpoint routing and connection controls.
- Improves navigation, page transitions, usage filters, compact layouts, and the macOS status menu.
- Adds one bilingual English and Simplified Chinese installation guide to the DMG.
- Keeps the install surface to the App, Applications shortcut, and one Markdown guide.

## macOS test package

Download `token-station_1.2.0_aarch64_UNSIGNED-UNNOTARIZED.dmg` and its `.sha256` file.

This DMG is unsigned, unnotarized, and for testing only. It does not provide Developer ID verification or an
Apple notarization ticket. Check the SHA-256 before opening it. Drag `token-station.app` to Applications. If
macOS blocks the App, open the bilingual Markdown guide and copy its one scoped Terminal command.

This pre-release does not provide CLI binaries, Intel macOS, Windows, Linux, or signed in-app update assets.

# Token Station v1.2.0（简体中文）

这是源码预发布版。它为 Apple Silicon 提供更完整的 macOS 拖拽安装体验，并包含 v1.1.3 之后
完成的产品更新。

## 主要更新

- 在概览中优先显示已连接的 Agent。
- 增加以模型为中心的 Agent 路由和路由预览。
- 增加模型搜索、批量价格导入和更新后的模型目录。
- 增加企业端点路由和连接控制。
- 改进导航、页面过渡、用量筛选、紧凑布局和 macOS 状态栏菜单。
- DMG 只提供一个中英双语 Markdown 安装说明。
- 安装界面只保留 App、Applications 快捷方式和这一个 Markdown 文档。

## macOS 测试安装包

请下载 `token-station_1.2.0_aarch64_UNSIGNED-UNNOTARIZED.dmg` 和对应的 `.sha256` 文件。

该 DMG 未签名、未公证、仅供测试。它不具备 Developer ID 身份验证或 Apple 公证票据。打开前
必须核对 SHA-256。把 `token-station.app` 拖到 Applications。如果 macOS 拦截 App，请打开这个
中英双语 Markdown 说明，并复制其中唯一一条、仅作用于 Token Station 的终端命令。

该预发布版不提供 CLI 二进制、Intel macOS、Windows、Linux 或签名的应用内更新资产。
