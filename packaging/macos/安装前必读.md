# Token Station 安装前必读

## 先确认下载来源

正式发布包应完成 Developer ID 签名和 Apple 公证。只使用从
[Token Station GitHub Releases](https://github.com/ballast-ai/token-station/releases)
等可信发布页面下载的 DMG。来源不明时请停止安装。

## 推荐安装方式

1. 双击 `安装 Token Station.command`。
2. 终端会检查 App 身份和代码签名，并说明准备执行的操作。
3. 确认后输入 `y` 或 `Y`。
4. macOS 会请求管理员密码，因为 App 要安装到 `/Applications`。输入密码时不会显示字符，
   这是终端的正常安全行为。

安装脚本只会安装并放行 `/Applications/token-station.app`，不会关闭系统全局安全检查，
也不会读取、保存、打印或上传管理员密码。如果目标位置存在其他应用，脚本会停止。
替换旧版 Token Station 前会创建临时备份；安装失败时会尝试恢复旧版。

## 不使用脚本时

把 `token-station.app` 拖到 DMG 中的 `Applications` 快捷方式。随后在 Finder 中右键点击
`/Applications/token-station.app`，选择“打开”，并在 macOS 提示中再次点击“打开”。

如果已经确认 DMG 来自可信发布页面，但右键打开仍失败，可以在终端执行只针对
Token Station 的命令：

```bash
sudo xattr -dr com.apple.quarantine /Applications/token-station.app
```

这条命令不会修改其他 App，也不会修改 SIP。不要对 `/Applications`、个人目录或其他宽泛
目录递归移除 quarantine。不要全局关闭 Gatekeeper。

## 安装遇到问题

请保留终端显示的错误信息，并在
[GitHub Issues](https://github.com/ballast-ai/token-station/issues) 中说明失败步骤、macOS
版本和 Mac 芯片类型。不要上传密码、私钥、Token、个人配置或包含用户名的完整路径。
