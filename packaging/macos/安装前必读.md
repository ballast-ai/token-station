# Read Before You Install Token Station

## Check the package

Use a DMG from the [Token Station GitHub Releases](https://github.com/ballast-ai/token-station/releases)
page or another source that the team confirms. Check the SHA-256 against the `.sha256` file. Stop if
the source or checksum does not match.

A file name that contains `UNSIGNED-UNNOTARIZED` identifies an unsigned test build. Apple did not
notarize this build. Gatekeeper can block it. Use it only for testing.

A standard release package must have a valid Developer ID signature and Apple notarization.

## Install the app

1. Open `安装 Token Station.command`.
2. Read the checks and actions that Terminal shows.
3. Enter `y` or `Y` to continue.
4. Enter your administrator password when macOS asks for it. Terminal does not show password characters.

The installer handles only `/Applications/token-station.app`. It does not disable system-wide security
checks. It does not read, store, print, or upload your password. It creates a temporary backup before it
replaces an earlier Token Station app. It tries to restore that backup if installation fails.

## Install without the script

Drag `token-station.app` to the `Applications` shortcut. In Finder, right-click
`/Applications/token-station.app` and select **Open**. Select **Open** again in the macOS message.

If macOS still blocks the app, read `macOS-无法打开怎么办.md`. Do not disable Gatekeeper or SIP.

# Token Station 安装前必读

## 检查安装包

只使用 [Token Station GitHub Releases](https://github.com/ballast-ai/token-station/releases) 页面
或团队确认来源中的 DMG。请用同目录的 `.sha256` 文件核对 SHA-256。来源不明或校验值不一致
时，请停止安装。

文件名含 `UNSIGNED-UNNOTARIZED` 表示该文件是未签名测试包。Apple 未对该文件完成公证，
Gatekeeper 可能拦截它。该文件仅供测试。

标准发布包必须具有有效的 Developer ID 签名和 Apple 公证。

## 安装 App

1. 打开 `安装 Token Station.command`。
2. 阅读终端显示的检查结果和操作说明。
3. 输入 `y` 或 `Y` 继续。
4. macOS 请求管理员密码时输入密码。终端不会显示密码字符。

安装脚本只处理 `/Applications/token-station.app`，不会关闭系统全局安全检查，也不会读取、
保存、打印或上传管理员密码。替换旧版 Token Station 前，脚本会创建临时备份。安装失败时，
脚本会尝试恢复旧版。

## 不使用脚本安装

把 `token-station.app` 拖到 `Applications` 快捷方式。在 Finder 中右键点击
`/Applications/token-station.app`，选择“打开”，再在 macOS 提示中点击“打开”。

如果 macOS 仍然拦截 App，请阅读 `macOS-无法打开怎么办.md`。不要关闭 Gatekeeper 或 SIP。
