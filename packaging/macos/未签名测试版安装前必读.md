# Token Station 未签名测试版安装前必读

## 这不是正式签名安装包

`token-station_1.1.3_aarch64_UNSIGNED-UNNOTARIZED.dmg` 未签名、未经 Apple 公证，
仅供测试。macOS Gatekeeper 会拦截它，Apple 也没有验证开发者身份。请只从团队确认的
可信来源取得文件，并核对随包提供的 `.sha256` 文件中的 SHA-256。来源或校验值不一致时
请停止安装。

## 推荐安装方式

1. 双击 `安装 Token Station.command`。
2. 终端会明确提示这是未签名、未公证的测试 App，并检查 bundle id 和 ad-hoc 代码签名。
3. 确认来源和 SHA-256 后，输入 `y` 或 `Y`。
4. macOS 会请求管理员密码，因为 App 要安装到 `/Applications`。输入密码时不会显示字符，
   这是终端的正常安全行为。

安装脚本只会处理 `/Applications/token-station.app`，不会关闭系统全局安全检查，
也不会读取、保存、打印或上传管理员密码。替换旧版前会创建备份，安装失败时会尝试恢复。

## 不使用脚本时

把 `token-station.app` 拖到 `Applications` 快捷方式。随后在 Finder 中右键点击
`/Applications/token-station.app`，选择“打开”，并在 macOS 提示中再次点击“打开”。

如果已经确认来源和 SHA-256，但右键打开仍失败，可以执行只针对 Token Station 的命令：

```bash
sudo xattr -dr com.apple.quarantine /Applications/token-station.app
```

这条命令不会修改其他 App，也不会修改 SIP。不要对 `/Applications`、个人目录或其他宽泛
目录递归移除 quarantine。不要全局关闭 Gatekeeper。

## 安装遇到问题

请保留终端显示的错误，并在
[GitHub Issues](https://github.com/ballast-ai/token-station/issues) 中说明失败步骤、macOS
版本和 Mac 芯片类型。不要上传密码、私钥、Token、个人配置或包含用户名的完整路径。
